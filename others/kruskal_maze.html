クラスカル法(の要領)を使って迷路を掘ろう


迷路をいっぱい生成する動画を見て、そんな方法があるのか→いわれてみれば確かに、と思ったので実装してみた。
迷路と言えば正方形のものが生成できればまあいいかなと思ったので、1辺の長さを入力すると良い感じに迷路を作ってくれるようにした。

前提知識として、最小全域木を構成するためのアルゴリズムの1つであるクラスカル法の理解が必要である。
気が向いたら後で追記する（グラフ・最小全域木・クラスカル法あたりの話を全部書かないといけないので大変なのである）。

方針としては、まず\(N \times N\)のマス目を用意し、左上の方をスタート、右下の方をゴールに設定し、1つ飛ばしで通行可能な道マスを配置していく。
例えば\(7 \times 7\)マスだったら、こういう感じにするわけだ。

#######
#S#.#.#
#######
#.#.#.#
#######
#.#.#G#
#######
で、この時のスタート、ゴール、通行可能マスを頂点とするグラフを考え、クラスカル法の要領で全域木を作ると、孤立点の無い迷路が出来上がるという寸法だ。

あまりうまい方法が思いつかなかったのでこんな感じにしてみる。
・入力\(N\)が奇数値になるよう調整する（実装を簡単にし、かつ、外周全体を壁で覆うため）
・\(W = \frac{N - 1}{2}\)とおく。
・\(W^2\)個の頂点を持つグラフを考える。頂点名は今後を考えて0-indexedとする。
・グラフについて、頂点\(p\)と頂点\(p + W\)の間に辺を張る
・グラフについて、頂点\(p\)と頂点\(p + 1\)の間に辺を張る（ただし\(p\)が\(W\)で割って\(W-1\)余る数のときは張らない）
このような操作によって得られるグラフは、最終的な迷路を抽象化したような図になる。
つまり、グラフの各頂点を\(W\)個ずつに区切って並べる。
0 1 2 ... W-1
W W+1 W+2 ... 2W - 1
...
という感じである。この時、上記の操作によって上下に並んだ頂点と、左右に並んだ頂点同士が結ばれているのが分かるだろうか。
あとはこのグラフに対して辺の順番をぐちゃぐちゃにしてクラスカル法の要領で全域木を作ればよい。

で、これによって得られた全域木を上手いこと迷路にしていく。
・\(N \times N\)のマス目を用意する。最初、これらのマスはすべて通過不能の壁マスとして考える。
・上から\(i\)行目、左から\(j\)列目のマスを\((i,j)\)と呼称することにする。これは0-indexedにする。
・先のグラフの頂点\(p\)と\(q\)の間に頂点があるという状態を、以下のように反映させる。
→頂点\(p\)と、マス\((2 \times (pをWで割った商) + 1, 2 \times (pをWで割った余り) + 1)\)を対応させる。頂点\(q\)も同様に対応させ、この2マスと、その間にあるマスを通過可能な道マスにする。
という操作をすることで、さっきのグラフとマス目を対応させることができる。
時間計算量がどれくらいになるかだが、およそ\(O(N^2)\)か\(O(N^2\alpha(N^2))\)程度で押さえられるのではないだろうか。多分グラフをぐちゃぐちゃしているタイミングが一番大変だろうし。
余りにも大きな迷路は生成できないが、\(100 \times 100\)マスの迷路程度なら余裕のよっちゃんで生成できるので、まあ実用上は何の問題もない。
実装は以下のとおり行った。

import random

class DisjointSetUnion:
    def __init__(self, N: int):
        self.number = N
        self.parent = [ -1 for _ in range(N)]
        self.size = [ 1 for _ in range(N)]

    def find(self, v : int):
        compress = []
        while self.parent[v] != -1:
            compress.append(v)
            v = self.parent[v]
        for c in compress:
            self.parent[c] = v
        return v

    def union(self, u: int, v: int):
        ru = self.find(u)
        rv = self.find(v)
        if ru != rv:
            if self.size[ru] < self.size[rv]:
                ru, rv = rv, ru
            self.parent[rv] = ru
            self.size[ru] += self.size[rv]

    def same(self, u: int, v: int):
        return self.find(u) == self.find(v)

def isin(x, W):
    return 0 <= x <= W ** 2 - 1

N = int(input())

if N % 2 == 0:
    N += 1

# 抽象化した迷路をクラスカル法の要領で繋ぐ
W = (N - 1) // 2
uf = DisjointSetUnion(W ** 2)
Edges = []
for i in range(W ** 2):
    if i < W ** 2 - W and isin(i + (N - 1) // 2, W ** 2):
        Edges.append([i, i + (N - 1) // 2])
    if i % W != W - 1 and isin(i + 1, W ** 2):
        Edges.append([i, i + 1])

# 頂点の生成順は毎回固定になるので、シャッフルしておく
random.shuffle(Edges)
Used_Edges = []
while Edges:
    u, v = Edges.pop()
    if uf.same(u, v):
        continue
    uf.union(u, v)
    Used_Edges.append([u, v])

# マス目を生成し、左上にスタート、右下にゴールを設置
# 各頂点に対応する部分を通行可能マスに変化
S = [[ "#" for _ in range(N)] for _ in range(N)]
for i in range(N):
    for j in range(N):
        if i == 1 and j == 1:
            S[i][j] = "S"
        elif i == N - 2 and j == N - 2:
            S[i][j] = "G"
        elif i % 2 == 1 and j % 2 == 1:
            S[i][j] = "."

# グラフをマス目に反映させる
while Used_Edges:
    p, q = Used_Edges.pop()
    uy, ux = p // W, p % W
    vy, vx = q // W, q % W
    uy, ux = 2 * uy + 1, 2 * ux + 1
    vy, vx = 2 * vy + 1, 2 * vx + 1
    S[(uy + vy)// 2][(ux + vx) // 2] = '.'

for i in range(N):
    print("".join(S[i]))
出力された迷路は見る限り割といい感じ。
ちょーっと横に伸びすぎな感じはあるけれど、まあ遠めに見ればちゃんとした迷路な感じはある。

実は今一つ迷路生成アルゴリズムについては理解ができていないところが多く、棒倒し法や穴掘り法が上手く動く理由を自分はまだうまく説明できない。
一方で、クラスカル法やプリム法といった「全域木を作る」というアルゴリズムが、迷路に応用できるというところは非常に腑に落ちた。
何のことはない、迷路を作るというのはつまり全域木を作るということだと言い換えられるのだ。考えてみればある意味当たり前なのだが、今の今までこれに気が付けなかった！
勿論、出来上がった迷路は特定の地点が必ず通過可能な道マスになっているなど、弱点もあるが、「どうしてこれがループを持たない迷路になるのか」については結構よく分かった。

手作業での実装は割と早く終わったが、結構行き当たりばったりに方針を考えてこういう形になった部分はあり、経験がいるなあなどと思った。

pyxelを使って100回迷路を生成して、迷路を解くコードを書いた。
疲れたときとかこれ見てる。

import random
import pyxel
import time

class DisjointSetUnion:
    def __init__(self, N: int):
        self.number = N
        self.parent = [ -1 for _ in range(N)]
        self.size = [ 1 for _ in range(N)]

    def find(self, v : int):
        compress = []
        while self.parent[v] != -1:
            compress.append(v)
            v = self.parent[v]
        for c in compress:
            self.parent[c] = v
        return v

    def union(self, u: int, v: int):
        ru = self.find(u)
        rv = self.find(v)
        if ru != rv:
            if self.size[ru] < self.size[rv]:
                ru, rv = rv, ru
            self.parent[rv] = ru
            self.size[ru] += self.size[rv]

    def same(self, u: int, v: int):
        return self.find(u) == self.find(v)

def isin(x, W):
    return 0 <= x <= W ** 2 - 1

def isin_grid(h, w):
    return 0 <= h <= N - 1 and 0 <= w <= N - 1

m_1 = [1, -1, 0, 0]
m_2 = [0, 0, 1, -1]

def dfs(u, v):
    if u == N - 2 and v == N - 2:
        return True
    for i in range(4):
        pyxel.pset(u, v, 10)
        pyxel.flip()
        nu = u + m_1[i]
        nv = v + m_2[i]
        if isin_grid(nu, nv) and S[nu][nv] != "#" and Visited[nu][nv] == -1:
            Visited[nu][nv] = Visited[u][v] + 1
            if not(u == 1 and v == 1):
                pyxel.pset(u, v, 0)
            else:
                pyxel.pset(u, v, 8)
            if dfs(nu, nv):
                return True
            pyxel.pset(u, v, 10)
            pyxel.flip()
    pyxel.pset(u, v, 0)
    return False

N = int(input())

if N % 2 == 0:
    N += 1

pyxel.init(N, N, title="Maze", fps=60)

for __ in range(100):
    # クラスカル法の要領による全域木構成
    # 抽象化した迷路をクラスカル法の要領で繋ぐ
    W = (N - 1) // 2
    uf = DisjointSetUnion(W ** 2)
    Edges = []
    for i in range(W ** 2):
        if i < W ** 2 - W and isin(i + (N - 1) // 2, W ** 2):
            Edges.append([i, i + (N - 1) // 2])
        if i % W != W - 1 and isin(i + 1, W ** 2):
            Edges.append([i, i + 1])

    # 頂点の生成順は毎回固定になるので、シャッフルしておく
    random.shuffle(Edges)
    Used_Edges = []
    while Edges:
        u, v = Edges.pop()
        if uf.same(u, v):
            continue
        uf.union(u, v)
        Used_Edges.append([u, v])

    # マス目を生成し、左上にスタート、右下にゴールを設置
    # 各頂点に対応する部分を通行可能マスに変化
    S = [[ "#" for _ in range(N)] for _ in range(N)]

    for i in range(N):
        for j in range(N):
            if i == 1 and j == 1:
                S[i][j] = "S"
            elif i == N - 2 and j == N - 2:
                S[i][j] = "G"
            elif i % 2 == 1 and j % 2 == 1:
                S[i][j] = "."

    # グラフをマス目に反映させる
    while Used_Edges:
        p, q = Used_Edges.pop()
        uy, ux = p // W, p % W
        vy, vx = q // W, q % W
        uy, ux = 2 * uy + 1, 2 * ux + 1
        vy, vx = 2 * vy + 1, 2 * vx + 1
        S[(uy + vy)// 2][(ux + vx) // 2] = '.'

    for i in range(N):
        for j in range(N):
            if S[i][j] == "S":
                pyxel.pset(i, j, 8)
            elif S[i][j] == "G":
                pyxel.pset(i, j, 11)
            elif S[i][j] == "#":
                pyxel.pset(i, j, 7)
        pyxel.flip()

    # dfs
    Visited = [[ -1 for _ in range(N)] for _ in range(N)]
    Visited[1][1] = 0
    dfs(1, 1)

    # bfsによる復元
    y = N - 2
    x = N - 2
    for _ in range(Visited[N - 2][N - 2] - 1):
        for i in range(4):
            nx = x + m_1[i]
            ny = y + m_2[i]
            if isin_grid(ny, nx) and Visited[ny][nx] == Visited[y][x] - 1:
                x = nx
                y = ny
                pyxel.pset(y, x, 14)
                pyxel.flip()
                break

    time.sleep(3)
    for i in range(N):
        for j in range(N):
            pyxel.pset(i, j, 0)
        pyxel.flip()
