Fisher-Yatesアルゴリズムについて

シャッフルに関するアルゴリズムを考えたい。
入出力に対して、以下のことを要請する。
入力：整数\(N\)
出力：\(0\)から\(N-1\)までの整数1つずつのみで構成された配列
ただし、出力として考えられるどの配列についても、出力される確率は等しいことを求める。
もしこれが実現できれば、任意の数列をランダムでシャッフルできることになる。

これを実現するアルゴリズムとして、Fisher-Yatesアルゴリズムが知られている。
手順は以下の通り。
p1.配列\(A=[0,1,2,3,...,N-1]\)を用意する。
p2.\(i=0,1,2,3,...,N-1\)に対して、以下の手順を繰り返し1度ずつ実施する
・\(0\)以上\(i\)以下の整数を1つ選び\(j\)とする。配列\(A\)の\(i\)番目の要素と\(j\)番目の要素を交換する。
p3.操作後の配列\(A\)を返す
このアルゴリズムが正当であること……つまり、
・アルゴリズムが有限回の動作で停止すること
・アルゴリズムが常に期待する結果を返すこと
を確かめたい。
操作は有限回しか行われないので、停止することについては自明としてよいだろう。
では、期待する結果を返すことはどうだろう？ 実は上手くいく。
一般に、\([A_{0},A_{1},...,A_{N}]\)を出力したいとき、\([0,1,2,...,N-1]\)を手順の通りに並び替えてそれを作り出す必要がある。
最後の\(N-1\)は上記の手順p2の中でも最後まで触られないものだ。ということは、\([0,1,2,...,N-2]\)の部分を先に上手く並び替えておいて、最後に\(N-1\)があるべき場所に\(A_{N-1}\)を置いておき、手順p2を最後に行うときにこの2つを入れ替えればよい。
「先にうまく並び替えておく」ことができるのかについては、今と同様に考えると\([0,1,2,...,N-3]\)を上手く並び替えられるかにかかっている。
この発想を繰り返せば、最終的に\([0]\)を上手く並び替えられるかという話になる。これは明らかに可能だ。
厳密に証明する場合は数学的帰納法を利用すればよいだろう。

時間計算量は、配列全体を1度ずつ舐める手順p2がネックで\(O(N)\)となる。
余程大きな数列をジェネレートしない限り現実的な時間、高速な操作ができる。
ただし、途中で使う乱数が偏ると出力も偏りうるので、ある程度良い乱数を使う必要がある。

Pythonによる実装は以下の通り。

import random

def fisher_yates(N):
    array = [i for i in range(N)]
    for i in range(len(array)):
        j = random.randint(0, i)
        array[i], array[j] = array[j], array[i]
    return array

N = int(input())
print(fisher_yates(N))
# -> [1, 3, 4, 2, 0]
しかし、Pythonだとrandom.shuffleで一発。C++も同じ。こんな面倒なことをする必要がない。
