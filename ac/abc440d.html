ABC440D Forbidden List 2

問題文はこちらから。
リストに載っていない、条件を満たす数を出力する問題。

実装例が込み入りすぎていて大変なことになっているが、実装のポイントはそこまで難しいわけではない。
まず、与えられるリストAに含まれていない数をすべてリストアップしたい。
ただし、具体的に全部列挙すると大変なことになるので、閉区間の形で書き表したい。
例えば、リストが(2,3,4,5)などの場合、[1,1],[6,∞]のように書くという感じ。
リストに含まれていない数の閉区間と、その区間端が「リストに含まれていない数のうち小さい方から何番目か？」を記したメモ（インデックスメモ）を持って、次の段階に進む。

各クエリを処理していく。
数\(x_i\)がどの閉区間に含まれているか（あるいはどの閉区間とどの閉区間の間にあるか）は、2分探索を行うことで高速に求めることができる。もし\(x_i\)がどの閉区間にも含まれていないのであれば、次に大きい閉区間の左端を新たに\(x_i\)として扱っても問題ない。
その後、「\(x_i\)が含まれる閉区間の左端と対応するインデックスメモの値」と「\(x_i\)-閉区間の左端」の和を求めることで、\(x_i\)が「リストに含まれていない数のうち何番目に小さい数か？」が分かる。
今出た値に\(y_i\)を足すと、「今求めたい数がリストに含まれていない数のうち何番目に小さい数か？」の答えが分かる。これの答えを\(num_p\)としよう。
今度はインデックスメモに対して、\(num_p\)が含まれる閉区間はどこか？ を調べればよく、これも2分探索で実現可能である。
後は先ほどと同様にして、求める数を出せるというわけである。

実装例は以下の通り。定数倍が重く時間ギリギリではあるが、回る。
時間計算量はできる閉区間の数を\(X\)として\(O(Q\log_{X})\)程度か。

# Lは昇順にソートされた数直線上の閉区間の列であるとする
#([[1,3], [5,6]]など)
# 値valがLのどの区間に属するか、またはどの区間とどの区間の間にあるかを出力する関数
def bisect_intervals(L, val):
    if L[0][0] > val:
        return "between", -1, 0

    l = 0
    r = len(L) - 1
    M = 0
    while l < r:
        M = (l + r) // 2
        if L[M][0] <= val <= L[M][1]:
            return "in", M
        elif val < L[M][0]:
            r = M
        elif val > L[M][1]:
            l = M + 1

    M = (l + r) // 2
    if L[M][0] <= val <= L[M][1]:
        return "in", M
    else:
        return "between", M - 1, M

N, Q = list(map(int,input().split()))
A = list(map(int,input().split()))

# 許可されていない区間を閉区間の列Forbidsで表す
A.sort()
Forbids = []
tmp = A[0]
for i in range(1, N):
    if A[i] == A[i - 1] + 1:
        continue
    Forbids.append([tmp, A[i - 1]])
    tmp = A[i]
Forbids.append([tmp, A[-1]])

# 許可されている区間を閉区間の列Permitsで表す
# Permitsの両端と対応するインデックスの閉区間Permits_idxも求める
# 許可されていない区間から求める
Permits = []
if Forbids[0][0] != 1:
    Permits.append([1, Forbids[0][0] - 1])
for i in range(len(Forbids) - 1):
    Permits.append([Forbids[i][1] + 1, Forbids[i + 1][0] - 1])
Permits.append([Forbids[-1][1] + 1, 10 ** 20])

Permits_idx = []
Permits_idx.append([1, Permits[0][1] - Permits[0][0] + 1])
for i in range(1, len(Permits)):
    Permits_idx.append([Permits_idx[-1][1] + 1, Permits_idx[-1][1] + Permits[i][1] - Permits[i][0] + 1])

for q in range(Q):
    x, y = list(map(int,input().split()))
    # xは許可されている区間のどれに属している？
    # どれにも属していない場合は、xより大きい最小の許可されている数字をxとしてよい
    cx = bisect_intervals(Permits, x)
    pivot = -1
    if cx[0] == "between":
        pivot = cx[2]
        x = Permits[pivot][0]
    else:
        pivot = cx[1]
    # xはOKな数のうち何番目に小さい数？ の答えがnum_x
    num_x = Permits_idx[pivot][0] + (x - Permits[pivot][0])
    # 「答えとなる数は許可されている数のうち何番目に小さい？」の答えがnum_p
    num_p = num_x + (y - 1)
    # num_p番目の数がどの閉区間に属するかを調べる
    ca = bisect_intervals(Permits_idx, num_p)
    # 求めた閉区間に属する数のうち、num_p - Permits_idx[ca[1]][0]番目に小さい数が答え(0-indexed)
    print(Permits[ca[1]][0] + (num_p - Permits_idx[ca[1]][0]))
なが～～～～いコードになってしまった上に、コメントを積極的に付さないとなんだかよく分からないコードになっている。
大変だ。
