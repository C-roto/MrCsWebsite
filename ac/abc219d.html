ABC219D Strange Mirroring

問題文はこちらから。
なが～～～～～～い繰り返し文字列の特定の箇所をこたえる問題。

\(K_i\)は\(10^{18}\)になることもあるので、順に文字列を生成しようものなら1クエリでTLEするケースもありうる。
文字列の生成方法を見ると、特徴的な形をしている。実際に紙に書いてみると、例えば文字列の\(N\)文字目は\(2 * N\)文字目の大文字/小文字を反転させたものであるし、\(3*N\)番目は\(N\)番目と同じもので、\(4 * N\)番目はそれと大小逆……のように繰り返される。
とりあえず大小を無視すると、同じ種類の文字が\(N\)回ごとに繰り返されるから、\(N\)で割った余りを見ようという発想にはなる。

もう少し思考を進めてみる。
\(i > N\)について、\(i\)文字目と同じ種類の文字がどこに登場するか、という視点で考えてみる。
数列を\(m\)回操作すると、長さは\(2^m \cdot N\)になっているわけなので、\(2^{m-1} \cdot N > i \geqq 2^m \cdot N\)とすると、\(i\)文字目の大小を反転させたものが\(i - 2^{m-1} \cdot N\)番目と一致するはずだ。
ということは、この問題は文字列の\(i - 2^{m-1} \cdot N\)番目を求める問題と実質的には同じということがわかるから、再帰的にこの問題を解くことができる。

実装例は以下の通り。

def ulreverse(s):
    if s.islower():
        return s.upper()
    else:
        return s.lower()

S = input()
Q = int(input())
K = list(map(int,input().split()))

answer = []
for q in range(Q):
    k = K[q]
    if 1 <= k <= len(S):
        answer.append(S[k - 1])
    else:
        m = 1
        while not(len(S) * 2 ** (m - 1) < k <= len(S) * 2 ** m):
            m += 1
        
        rev = 0
        while m > 0:
            if k > len(S) * 2 ** (m - 1):
                k -= len(S) * 2 ** (m - 1)
                rev += 1
            m -= 1

        if k == 0:
            k = len(S)

        if rev % 2 == 0:
            answer.append(S[k - 1])
        else:
            answer.append(ulreverse(S[k - 1]))
print(*answer)
いわゆるダブリングとか呼ばれる手法とほとんど同じような感覚で求めることができる。
