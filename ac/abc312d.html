ABC312D Count Bracket Sequences

問題文はこちらから。
?を(か)に変えて、括弧列をいくつ作れるか考える問題。

この問題における括弧列の定義は他の問題でもよく見かける。
全体が括弧列になっていることと、以下の2条件をともに満たすことは同値である。
・文字列全体で登場する"("の個数と")"の個数が等しい
・途中で"("の個数よりも")"の個数の方が多くなっていない
なので、途中経過を見て、それぞれ先頭の文字から順に「"("の個数-")"の個数」としてあり得る値を動的計画法などで管理すればよい。
具体的にはdpテーブルを以下のようにして持つ
\(dp[i][d] = Sのi文字目までを見たときに、含まれる"("の個数-")"の個数がちょうどd個である文字列の個数\)
このようにすれば、Sのi文字目が"("だった時は、i-1文字目までの結果がそのまま上にスライドし、")"だったときは下にスライドし、"?"だった時は両方が同時に起きる（どっちを先に処理しても結果には影響しない）。
後はdpテーブルにおいてSの末尾まで見た時に、"("と")"の差がちょうど0になっている文字列がいくつあるかを見ればよい。
勿論modを途中で取るのを忘れないようにする。
DPの時間計算量はSの長さをNとして、\(O(N^2)\)程度で収まるはずだ。
実装例は以下の通り。

S = input()

dp = [ [0 for _ in range(len(S) + 1)] for __ in range(len(S))]
mod = 998244353

if S[0] != ")":
    dp[0][1] = 1

for i in range(1, len(S)):
    for j in range(len(S) + 1):
        if S[i] == "(":
            if 0 <= j + 1 <= len(S):
                dp[i][j + 1] += dp[i - 1][j]
                dp[i][j + 1] %= mod
        elif S[i] == ")":
            if 0 <= j - 1 <= len(S):
                dp[i][j - 1] += dp[i - 1][j]
                dp[i][j - 1] %= mod
        else:
            if 0 <= j + 1 <= len(S):
                dp[i][j + 1] += dp[i - 1][j]
                dp[i][j + 1] %= mod
            if 0 <= j - 1 <= len(S):
                dp[i][j - 1] += dp[i - 1][j]
                dp[i][j - 1] %= mod

print(dp[-1][0])
簡単目だが、それは制約がdpなど何か不思議なやり方を示唆しているからにすぎない気もする。
あと前に括弧列の対応について見たことがあるかないかとかも大事か。
bfと略される某難解プログラミング言語の処理系とか調べたことがあると、括弧列の対応の大事さが分かるような気もする。
