問題文はこちらから。
指定範囲内に数列を収める問題。

\(A_3\)以降に対して操作をする必要がなさそうなことは何となく分かる（直観的には、\(A_1,A_2\)という範囲の外側をいじった方が効率が良さそうだろう）。
よって、\(A_1,A_2\)をいじることで、その間に\(M\)個の値が入るようにする方針で考える。

\(A_1,A_2\)の間に入る\(M\)個の値は、与えられた数列を昇順にソートした際に連続していることが必要である。
ソート後の\(A_3,A_4,...,A_N\)を、改めて\(S_1,S_2,...,S_{N-2}\)と書くことにする。
この時、\(M\)個の両端となる点は\(S_i\)と\(S_{i+M}\)である（ただし、\(i=1,2,...,N-M-2\)）。
よって、各\(i\)について\(A_1とS_i\)が一致するように\(A_1\)を減算（ただし\(A_1\)の方がもともと小さいときは何もしない）、\(A_2とS_{i+M}\)が一致するように\(A_2\)を加算（ただし\(A_2\)の方がもともと大きいときは何もしない）してやると、少なくとも\([A_1,A_2]\)の間に\(M\)個以上の値が入るのは明らかだ。
この時の操作回数は\(\max(0, A_1 - S_i) + \max(0, S_{i+M} - A_2)\)回だ。
この値の最小値を\(Y\)とする。また\(\max(0, A_1 - S_i) + \max(0, S_{i+M} - A_2) = Y\)となるような\(i\)を、そのような値が\(X\)個あるとして、\(1 \leqq x \leqq X\)なる整数\(x\)を用いて\(m_x\)と書くとする。
以下では、どのように操作を行っても、\(Y\)回以上の操作が必要であることを示す。

まず、もともと\([A_1,A_2]\)に\(M\)個の値があるなら、最小の操作回数は0回となる。
この時は\(S_j \geqq A_1\)を満たす最小の\(j\)を取れば、\(\max(0, A_1 - S_j) + \max(0, S_{j+M} - A_2) = 0\)を達成できる。
そうでない時について考える。
\(A_1 \ge A_2\)であるとき、一旦\(A_1=A_2\)となるように動かす必要があるから、\(A_2-A_1\)回の操作は最低限必要である。
そこから、\(S_i\)から\(S_{i+M}\)を\([A_1, A_2]\)に入れるためには、最低\(\max(0, A_1 - S_i) + \max(0, S_{i+M} - A_2)\)回の操作が必要になる（S側を動かすにせよ、A側を動かすにせよ）。
\(A_1 \leqq A_2\)であるときは、今ほどの議論の\(A_2-A_1\)のくだりが無くなるだけで、やはり\(S_i\)から\(S_{i+M}\)を\([A_1, A_2]\)に入れるためには、\(\max(0, A_1 - S_i) + \max(0, S_{i+M} - A_2)\)回は掛かる。

よって、結局\(\max(0, A_1 - S_i) + \max(0, S_{i+M} - A_2)\)の値の最小値を求めるというのが正当な手順になる。
配列のソートがネックになるため、時間計算量は\(O(N\log_{}{N})\)程度で抑えられ、無論制約下では高速である。
実装例は以下の通り。

N, M = list(map(int,input().split()))
A = list(map(int,input().split()))

l = A[0]
r = A[1]
nA = A[2:]
nA.sort()

answer = 10 ** 10
for i in range(N - 2):
    if i + M - 1 <= N - 3:
        check = max(0, l - nA[i]) + max(nA[i + M - 1] - r, 0)
        if check < answer:
            answer = check
    else:
        break

print(answer)
