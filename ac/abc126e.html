ABC126E 1 or 2

問題文はこちらから。
カードに書いてある数字を、幾つかのヒントから絞り込んで、最低限をチェックして全体を当てる問題。

NoviStepsではUnion-Findの練習問題として取り上げられていた問題。
与えられたヒントは
・「Zの値が偶数なら\(A_X, A_Y\)は同じ数字（ともに1か2）」
・「Zの値が奇数なら\(A_X, A_Y\)は違う数字」
と読み替えることができる。もう一段抽象化すると、
・ヒントが与えられた際、もう片方のカードの数字が分かっていればもう片方のカードの数字も確定する。
と言える。
もう少し広く考えると、「この数字が確定すると連鎖的に他の数字も確定する」という関係でグループを作ると、そのグループの個数が求める答えになる。
そして先ほどの抽象化から、ヒントで言及された添え字は、Zの値にかかわらず同グループと見なせばいい。
したがって、すべてのクエリについて普通にUnion-Findでグループ分けし、異なるグループの数を挙げれば答えになる。
実装例は以下の通り。

class DisjointSetUnion:
    def __init__(self, N: int):
        self.number = N
        self.parent = [ -1 for _ in range(N)]
        self.size = [ 1 for _ in range(N)]
 
    def find(self, v : int):
        compress = []
        while self.parent[v] != -1:
            compress.append(v)
            v = self.parent[v]
        for c in compress:
            self.parent[c] = v
        return v
 
    def union(self, u: int, v: int):
        ru = self.find(u)
        rv = self.find(v)
        if ru != rv:
            if self.size[ru] < self.size[rv]:
                ru, rv = rv, ru
            self.parent[rv] = ru
            self.size[ru] += self.size[rv]
 
    def same(self, u: int, v: int):
        return self.find(u) == self.find(v)

N, M = list(map(int,input().split()))
uf_asosiate = DisjointSetUnion(N)
for _ in range(M):
    X, Y, Z = list(map(int,input().split()))
    X -= 1
    Y -= 1
    uf_asosiate.union(X, Y)

S = set([uf_asosiate.find(i) for i in range(N)])
print(len(S))
「同じ数字になる組」で分けようとすると大変だが、それが本質でないことに気がつけるかどうかという問題。
