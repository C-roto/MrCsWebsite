ABC252E Road Reduction

問題文はこちらから。
連結を保ったままなるべく道を削る問題。

最小全域木かと思ったが、最小全域木は必ずしも問題で求められているグラフであるとは限らない。
調べてみると、このようなグラフは「最小経路木」と呼ばれているらしい。
最小経路木を作る方法は知らなかったが、NoviSteps経由でこの問題を除いたのでDijkstra法を使うことまでは分かっていた。
これまであまり意識したことがなかったが、Dijkstra法で得られる「経路」は必ず木になるという事実があることに気が付いた。
Dijkstra法を行う際に真に小さい経路のみを取っているのに、経路が木にならないとすると、どこかに閉路ができてしまい、すると最短経路を2つ取る頂点が現れてしまうので直観的にはおかしい。厳密な証明は一旦置いておいて、何となくこの事実は飲み込んでおくことにする（良くないので近いうちに証明したいところだが）。
なので、Dijkstra法で頂点を更新する際に、使った辺を記録しておけばよい。
毎度のことだが、INFの値は充分大きな値に設定しないとバグる（1敗）。
実装例は以下の通り。

import heapq

N, M = list(map(int,input().split()))
G = [ list() for _ in range(N)]
D = dict()
for i in range(M):
    a, b, c = list(map(int,input().split()))
    a -= 1
    b -= 1
    G[a].append((b, c))
    G[b].append((a, c))
    D[(a, b)] = i

INF = 10 ** 30

dist = [ INF for _ in range(N)]
dist[0] = 0

que = []
heapq.heapify(que)
heapq.heappush(que, [dist[0], 0])
spaningtree = [ -1 for _ in range(N)]

while que:
    p = heapq.heappop(que)
    v = p[1]
    d = p[0]

    if d > dist[v]:
        continue

    for e in G[v]:
        if dist[e[0]] > dist[v] + e[1]:
            dist[e[0]] = dist[v] + e[1]
            heapq.heappush(que, [dist[e[0]], e[0]])
            spaningtree[e[0]] = v

answer = []
for i in range(N):
    a = i
    b = spaningtree[i]
    if a > b:
        a, b = b, a
    if a == -1:
        continue
    d = D[(a, b)]
    answer.append(d + 1)

print(*answer)
Dijkstra法を使ってこんなことができるんだなあという驚きがあった。
言われてみたらそうなんだけど言われるまで意識したことがなかった。
