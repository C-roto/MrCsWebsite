ABC472E Odd Cycle

問題文はこちらから。
単純連結無向グラフに奇数長閉路が存在するかを判定し、あるなら例の出力まで行う問題。

存在判定はそれほど難しくない。2部グラフ(端的には、頂点を黒か白かのいずれかの色で塗り分ける時、隣接する頂点同士が同色にならないような塗分け方が存在するようなグラフ)でないことと、奇数長の閉路を持つことは同値だからである。
証明は調べれば色々出てくる（後でこのページにも軽い説明は残したい）。
2部グラフの判定はDFSでもBFSでも書けるが、今回はBFSで書いてみる。

実際に構築するのがやや面倒。
とりあえず2部グラフでない場合、BFSでの彩色中に隣接する同色頂点が生まれるのは間違いないので、最初に衝突する2頂点を記録しておく(以下、一方を\(P\)、もう一方を\(Q\))と呼ぶ。
点\(P\)から順に、頂点\(1\)まで辿ってきた道を遡っていき、通った辺を逐次記録しておく。
同様に、点\(Q\)から順に、頂点\(1\)まで辿ってきた道を遡っていき、通った辺を逐次記録しておく。
（BFS中に「直前どの頂点から遷移してきたか」を記録しておけばこれはすぐに可能である）
点\(P\)からの道と点\(Q\)からの道が最初に合流する頂点を\(R\)とすると、\(R→P→Q→R\)という閉路を取ることができる。この閉路は必ず奇数長になっていることが簡単に示せる。
(証明)
　\(R\)が既に彩色済みの頂点であることは明らかである。
　もし\(R\)が\(P,Q\)と同色ならば、\(R→P\)の間では白と黒が偶数回切り替わるので、辺も偶数本ある。これは\(Q→R\)間も同様である。
　\(P→Q\)間には1本しか辺がないので、偶数本+偶数本+1本は奇数本である。
　\(R\)と\(P,Q\)が異色の場合も同様にして奇数本+奇数本+1本は奇数本である。
よって、この閉路を提出すればよい。
時間計算量は（以下の例だとやや面倒なことをやっているが）BFSと、解答が存在する場合の構築部分がネックであろうか。
前者の計算量は\(O(N+M)\)で抑えられるし、後者の計算量は辺の数の定数倍で抑えられるはずだから、1回の入力の全体で扱う頂点の個数を\(N_{sum}\)、辺の本数を\(M_{sum}\)とすれば、全体の時間計算量は\(O(N_{sum}+M_{sum})\)で抑えらえるはずだ。
今回の入力制約下では充分に高速だろう。
実装例は以下の通り（解答構築部が明らかにごちゃごちゃしているのでそのうち直したい）

import collections

T = int(input())

for t in range(T):
    N, M = list(map(int,input().split()))
    G = [ set() for _ in range(N)]
    for i in range(M):
        a, b = list(map(int,input().split()))
        a -= 1
        b -= 1
        G[a].add(b)
        G[b].add(a)
    Color = [ -1 for _ in range(N)]
    Parents = [ -1 for _ in range(N)]

    # 2色で塗り分け可能か⇔奇数長の閉路を含むかの判定
    que = collections.deque([0])
    Color[0] = 0
    Parents[0] = -2
    Same_color = []
    ok_flag = True
    while que:
        p = que.popleft()
        for q in G[p]:
            if Color[q] == -1:
                que.append(q)
                Parents[q] = p
                if Color[p] == 0:
                    Color[q] = 1
                else:
                    Color[q] = 0
            # 色が衝突したら衝突した色を記録しておく
            if Color[q] == Color[p]:
                Same_color.append(p)
                Same_color.append(q)
                ok_flag = False
                break
        if ok_flag == False:
            break

    # 奇数長閉路の構築
    if ok_flag == False:
        answer = [Same_color[0] + 1]
        p = Same_color[0]
        founded = set([p])
        # 衝突地点の一方から頂点1に向かって辺を伸ばす
        while Parents[p] != -2:
            answer.append(Parents[p] + 1)
            founded.add(p)
            p = Parents[p]
        answer.reverse()
        q = Same_color[1]
        answer.append(q + 1)
        # 衝突地点のもう一方から頂点1に向かって辺を伸ばす
        # 先に通った頂点を再び通りそうになったらそこで止める（その時点で閉路ができている）
        while Parents[q] != -2:
            if q in founded:
                break
            answer.append(Parents[q] + 1)
            q = Parents[q]
        answer.reverse()
        # 余分な頂点を削除する
        while answer[-1] != answer[0]:
            answer.pop()
        # 合流地点が2重カウントされているので削除する
        answer.pop()

    if ok_flag:
        print(-1)
    else:
        print(len(answer))
        print(*answer)
