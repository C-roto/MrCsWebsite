ABC464C Plumage Palette


問題文はこちら。
色が変わる摩訶不思議な鳥を観察する問題。

すべての鳥について、変化の回数は高々1回しかない。観察日数もそんなに長くない。
すると、全部を愚直に検証してもよさそうに思う。

前準備として、各鳥の情報を、色が変化する日数の小さい順にソートして配列にもって置く。
その後は以下のように検証するのが良いだろう。
・仮想的な「0日目」の状態を連想配列で持っておく（keyが色の種類、valueがその色の鳥の数）。
　これは各\(A_i\)の値について調べれば良い。
・次に、now=0とし、iを1からMまで動かして以下の操作を行う。
→配列の先頭を見て、もしD_[now]=iなら、状態を記録している連想配列から\(A_{now}\)の鳥を1匹減らし、\(B_{now}\)の鳥を1匹増やす。その後nowを1インクリメントして同じ動作を行う。
　D[now]=iでないなら何もしない。
→連想配列に含まれるkeyの種類数を出力する

実際には現在の鳥の種類数を管理する変数racesを用意して、連想配列をいじるのと同様に整合性を取るのが楽だろう。
実装例は以下の通り。

def dictadd(D, e):
    global races
    if e not in D:
        D[e] = 1
        races += 1
    else:
        D[e] += 1

def dictminus(D, e):
    global races
    D[e] -= 1
    if D[e] == 0:
        D.pop(e)
        races -= 1

N, M = list(map(int,input().split()))
Birds = []
for _ in range(N):
    Birds.append(list(map(int,input().split())))
Birds.sort(key = lambda x:x[1])
answer = []

States = dict()
idx = 0
races = 0
# イニシャライズ
for i in range(N):
    dictadd(States, Birds[i][0])

for i in range(1, M + 1):
    while idx < N and Birds[idx][1] == i:
        dictminus(States, Birds[idx][0])
        dictadd(States, Birds[idx][2])
        idx += 1
    print(races)
計算量は、各鳥をただ1度ずつみる前提と、全部の日をただ1度ずつ走査するという前提から、日数と鳥の数の多い方に依存するので、\(O(N + M)\)だ。
ループ内のwhile条件を逆に書くと、Birds[N]という存在しない場所を走査させてしまいエラーになるので注意（1敗）。よくやるんだけど、何でか治らないんだよねこのミス。
引数に指定していない変数を無理やりいじる良くないスタイルが出てしまっている。
動けばいいの精神は時に良くないと思うのでした。
