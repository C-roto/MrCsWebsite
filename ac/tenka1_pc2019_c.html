Tenka1 Programmer Contest 2019 C Stones

問題文はこちらから。 一列に並んだ白黒の石であって、特定の並びが出ないように石の色を変える問題。

最終的な形としては"...…..##…#"のように、左の方が"."で、右の方が"#"になっている状態を作れれば良い。
この時「例えば右の方にある"."を"#"に置き換える」のような、雑な貪欲法を使うと失敗する（N=10,S="##.#....##"などの例が分かりやすい）。
ゴールの形が決まっているという話をもう少し掘り下げたい。左の方がずっと"."で、右の方がずっと"#"という形というのは、左から\(i(i=0,1,2...,N)\)番目までを"."にするということを指す。
つまり\(i\)の選び方\(N + 1\)通りを調べればすべてのあり得るゴールを調べたことになる。

調べ方について考える。具体的にどこに白石と黒石があるかは問題ではなく、ある地点より前に黒石がいくつあって、ある地点より後ろに白石がいくつあるかさえわかれば、その合計が色を変えるべき石の数になる。
これは白石と黒石の各累積和を取れば、毎回定数時間で算出できる。
というわけで、先の各ゴールに対応する地点に対して、毎回定数時間で操作すべき石の個数が分かるので、ループの回数がネックとなり、全体の時間計算量は\(O(N)\)程度で抑えられる。
実装例は以下の通り。

N = int(input())
S = list(input())

white = 0
for i in range(N):
    if S[i] == ".":
        white += 1
    else:
        break

B = [ 0 for _ in range(N)]
W = [ 0 for _ in range(N)]
for i in range(N):
    if S[i] == ".":
        W[i] = 1
    else:
        B[i] = 1

for i in range(N - 1):
    W[i + 1] += W[i]
    B[i + 1] += B[i]

answer = min(W[-1], B[-1])
for i in range(N - 1):
    s = B[i] + (W[-1] - W[i])
    if answer > s:
        answer = s

print(answer)
