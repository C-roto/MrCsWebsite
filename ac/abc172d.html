ABC172D Sum of Divisors

問題文はこちらから。
ある値とその値の約数の個数の積の総和を求める問題。

真正面から約数の個数を求める必要がある問題。
かといって1つずつ求めていると1つあたりおよそ時間計算量で\(O(\sqrt{N})\)程度かかってしまうので、全体で時間計算量\(O(N\sqrt{N})\)となってしまい、この制約だと多分間に合わない。
だが、「\(N\)以下であって\(i\)で割り切れるものをピックアップする」を各\(i=1,2,...,N\)に対して行う方針に切り替えると時間計算量はぐっと減る。
\(N\)以下であって\(i\)で割り切れるものの個数は大体\(\lfloor \frac{N}{i} \rfloor\)個だから、その\(i=1,2,...,N\)についての総和は（調和級数を途中で打ち切ったものがlogで押さえられることを使うと）大体\(O(N\log_{}{N})\)個程度になると考えられる。
時間計算量もこの式で押さえられるはずなので、これなら間に合う可能性が出る(現在のAtcoder環境下ならPyPyでも\(N=10^7\)で1000msかからない程度だった)。
あとは愚直に書けて足すのを繰り返すと答えが出る。
実装例は以下の通り。

N = int(input())
P = [ 1 for _ in range(N + 1)]
for i in range(2, N + 1):
    for j in range(i, N + 1, i):
        P[j] += 1

answer = 0
for i in range(1, N + 1):
    answer += i * P[i]
print(answer)
