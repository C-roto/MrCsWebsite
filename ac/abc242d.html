ABC242D ABC Transform

問題文はこちらから。
文字を置き換え続けて長くなった文字列の何番目かの文字を答える問題。

愚直に文字列に対して操作を行い続けるのは厳しい。
t回操作を行った後のk文字目は、t-1回目の操作で\(\frac{k}{2}\)(の小数点以下上げ)文字目にあった文字によって決まることに注意する。
例えば、3回目の操作時に4文字目が"A"だったとすると、4回目の操作時の7文字目は"B"になるし、8文字目は"C"になることが容易にわかるだろう。
よって、操作を遡って、再帰的に文字を求めることを考える。
もし、遡っている途中でt=0になったなら、最初の文字列のその文字を返せばよい。
そうでないなら遡り続ければいいが、操作回数の上限に対する制約が大きいので、愚直に遡り続けるわけにはいかない。
1文字目は明らかに周期3でループすることが分かるので、遡り続けて1文字目になれば、最初に1文字目まで遡った数の3で割った剰余が分かれば計算できる。
文字数の最大は\(10^18\)文字目だから、最大でも60回程度遡れば1文字目に辿りつく。
時間計算量で言うと、大体\(O(N + Q(min(t, \log_{}{max(k)})))\)くらいで押さえられ、まあ高速だろう。
実装例は以下の通り(65がマジックナンバーすぎるが、chr(65) = "A"ということである)。

def letter_search(t, k):
    if t == 0:
        return S[k]
    if k == 0:
        s = ord(S[0]) - 65
        if t % 3 == 1:
            s += 1
            s %= 3
        elif t % 3 == 2:
            s += 2
            s %= 3
        return chr(65 + s)
    else:
        if k % 2 == 0:
            a = letter_search(t - 1, k // 2)
            s = ord(a) - 65
            s += 1
            s %= 3
        else:
            a = letter_search(t - 1, k // 2)
            s = ord(a) - 65
            if s == 0:
                s = 2
            else:
                s -= 1
        return chr(65 + s)

S = input()
Q = int(input())
for _ in range(Q):
    T, K = list(map(int,input().split()))
    K -= 1
    print(letter_search(T, K))
