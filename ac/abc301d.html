ABC301D Bitmask


問題文はこちら。
2進表記の一部と上限が与えられ、上限以下の最大値を求める問題。

色々考えた。
?を0か1かならDPって手もありそうだし、条件を満たす/満たさないなら二分探索も頭をよぎる。
一方で、DPは保持しておくべき情報が多すぎる（一部における最大値が全体の最大値につながるとは限らない）し、二分探索も「ある値以上であることと条件を満たすことが同値」という性質じゃないのでダメそう。
「ある方法が使えない」と確信を持てることも大事なことな気がする。

結局色々考えた末、これが2進数なので貪欲法が普通に使えることに気が付く。
2以上の整数\(M\)について、2進法において\(M\)桁目が1である数と、\(M-1\)桁目以下がすべて1である数を比較すると、前者の方が勿論大きい(10進法では\(2^M\)と\(2^0+2^1+2^2+...+2^{M-1}=2^M-1\)だし、桁の趣旨を考えれば自明)。
ということは、桁が大きい方から見ていって「?を1にしても条件を満たすならそうする」という貪欲法が正当になりそうだ（それを取らずに、後から下桁を回収した方が大きくなる可能性は0）。

元々1である位だけを取り出してまとめておくと計算しやすい。
?が全部0でも、もともとが1である位のみで構成される数が条件を満たす可能性があるので、その考慮を忘れないようにする。
僕は1回忘れて「なんで通らんのやろ～？」とか呟いていました。

実装例はこちら。

S = input()
N = int(input())

ones = 0
ques = []
for i in range(len(S)):
    if S[-1 - i] == '1':
        ones += 2 ** i
    elif S[-1 - i] == '?':
        ques.append(i)

ques.reverse()

answer = ones
ok_flag = False
for q in ques:
    if answer + 2 ** q <= N:
        answer += 2 ** q
        ok_flag = True

if ok_flag:
    print(answer)
else:
    if answer <= N:
        print(answer)
    else:
        print(-1)
