ABC362E Count Arithmetic Subsequences

問題文はこちらから。
数列の中の幾つかの数字を抜き出して等差数列になるものの個数を求める問題。

部分列は全部で\(2^{80}-1\)通りあるわけなので、もちろんすべてを調べることは難しい。
一方で\(N\)の値の小ささというかなり重要な制約があるので、こいつを活用したいと考えるのもまた自然だ。

こういうのは分かるところから埋めていくのがポイントになりそうだ。
まず、長さ1の等差数列の個数だが、これは長さ1の部分列の個数と等しいから、求める値はいついかなる時でも\(N\)個になる。
また、長さ2の等差数列の個数だが、これは長さ2の部分列の個数と等しい。よって、求める値は\(\frac{N(N - 1)}{2}\)通りだ。
長さ3の等差数列については、長さ2の等差数列の後ろに1つ（末項より後ろにある）数をくっつけたものであって、等差数列になっているものを考えればよい。
これは、先に\(\frac{N(N - 1)}{2}\)個の長さ2の等差数列に対して、「末項が何で公差が何の数列か？」を記録しておけば、動的計画法で上手く行く。
要するに、\(dp_{p,i,d}\)を「項数p(\(\geqq 2\))、末項i、公差dの等差数列の個数」としたとき、こういう遷移を考えればよい。
\(dp_{p + 1,i,d} = \sum_{d = A_i - A_j \land j < i} dp{p,j,d}\)
この遷移は各\(i\)に対し\(j < i\)なる\(j\)をすべて確かめれば良く、pythonならdict型でデータを持つなりすれば各1回の\(j\)のチェックに対して定数時間でこれは確認できる。
よって、時間計算量\(O(N^2)\)で列挙は可能である。
公差4以上に対しても同様の方法で列挙は可能である。
各項数について、あり得る\(i, j\)のペアは高々\(O(N^2)\)個しかないので、各項数における動的計画法の結果の総和を求めるときにも、dict型のkey, valueのペアは高々\(O(N^2)\)個しか存在しない。各key, valueに対する和を取ってmodを取る作業を定数時間とみなすなら、総和を取る操作も時間計算量\(O(N^2)\)程度で完了する。
よって、各公差に対して上記の操作を行っても、時間計算量\(O(N^3)\)程度で完了するだろう。制約に対して明らかに高速なはずだ。
実装例は以下の通り。

N = int(input())
A = list(map(int,input().split()))
mod = 998244353

# 項数1のものはN個
answer = [N]
# dp[p][i][d] = 項数pの等差数列であって、A_iを末項とし公差dのものの個数
dp = [ [ dict() for _ in range(N)] for _ in range(N + 1)]
for i in range(N):
    for j in range(i + 1, N):
        if A[j] - A[i] not in dp[2][j]:
            dp[2][j][A[j] - A[i]] = 1
        else:
            dp[2][j][A[j] - A[i]] += 1

for k in range(3, N + 1):
    for i in range(N):
        for j in range(i + 1, N):
            if A[j] - A[i] in dp[k - 1][i]:
                if A[j] - A[i] not in dp[k][j]:
                    dp[k][j][A[j] - A[i]] = dp[k - 1][i][A[j] - A[i]]
                else:
                    dp[k][j][A[j] - A[i]] += dp[k - 1][i][A[j] - A[i]]
                dp[k][j][A[j] - A[i]] %= mod

for i in range(2, N + 1):
    tmp = 0
    for j in range(N):
        for v in dp[i][j].values():
            tmp += v
            tmp %= mod
    answer.append(tmp)

print(*answer)
dp的発想に辿り着くのはそんな難しくない問題な気もするが、データの持ち方や時間計算量の判断に注意が必要そうに見える。
