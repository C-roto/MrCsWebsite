ABC337E Bad Juice

問題文はこちらから。
腐ったジュースを特定するために、友人の腹を破壊する問題。

謎解きゲームとかWebの脱出ゲームをやったことがある人なら、同種の問題を見たことがあるだろう。
昔々、NHK高校講座で秋山仁先生が数学パズルとして類似のマジックを紹介していたこともあった。
そういえば競プロ的な視点で解体してみたことってないような気もする。

\(M\)の値としてあり得る最小の値は\(\lceil \log_{}{N} \rceil\)人である。
理由は2進法で見てみると分かりやすい。
まず、今回我々が得られる情報は、各人が腹を壊したか、そうでないかについての情報である。
これらの結果は\(M\)人について\(2^M\)通りある(\(M=2\)の場合だと、腹を壊さない/壊さない、壊す/壊さない、壊さない/壊す、壊す/壊すの\(4=2^2\)通り)。
つまり、\(M\)人の腹痛の様子から、我々は\(2^M\)通りの結果しか得られないのである。
要はどんなふうにジュースを分けたとしても、腹痛がどう発生するかの結果は\(2^M\)通りしかありえないのだから、ジュースの方が結果より多かった（つまり\(N > 2^M\)だった）とすると、区別できない(結果が同じになる)ジュースの組が発生してしまう。

より形式的な書き方 友達を\(M\)人呼ぶとき、誰にどのジュースをふるまうかの組み合わせ(以下、単に「ジュースのふるまい方」とする)全体を\(F_M\)とする。
例えば\(M=2\)のとき、\(F_2\)の元\(((1,2),(3,4))\)は人1にジュース1,2を、人2にジュース3,4をふるまうことを意味するとする。
あるジュースのふるまい方\(f \in F_M\)について、ジュース\(i\)が腐っている時に得られる結果(問題文中の\(S\))は明らかに一意に定まるため、これを\(f(i)\)と書くとする。

もし\(N > 2^M\)だった場合、鳩ノ巣原理から、いかなるジュースの振り分け方\(f \in F_M\)に対しても、ある相異なるジュースの組\(i\),\(j\)が存在して\(f(i)=f(j)\)となることが示せる(\(f(i)\)のあり得る値の個数を巣箱とし、ジュースの番号の取りうる値を鳩とする、とすれば分かりやすいか)。
これはつまり、ジュース\(i\)と\(j\)のうち、どちらが腐っているか区別ができないということを指すので、「確実に特定する」ことは原理上絶対に不可能だということを表している。

これにより、明らかに\(N \leqq 2^M\)が必要であると分かった。
これを満たす最小の\(M\)、つまり\(\lceil \log_{}{N} \rceil\)が充分な人数であることを示す。
分け方としては以下のようにすればよい。
・人1には、2進法表記した時、下1桁目が1の番号のジュースをすべてふるまう。
・人2には、2進法表記した時、下2桁目が1の番号のジュースをすべてふるまう。
……
・人\(i\)には、2進法表記した時、下\(i\)桁目が1の番号のジュースをすべてふるまう。
……
もし\(N\)が2の累乗でない場合は、\(N\)を2進法表記した時の桁数は\(\lceil \log_{}{N} \rceil\)なので、人\(i\)が腹を壊しているかどうか見れば、腐っているジュースの番号を2進法表記した時の下\(i\)桁目のビットが1かどうか分かる。
腐ったジュースの番号\(j\)の2進法での桁数は勿論\(\lceil \log_{}{N} \rceil\)以下なので、各ビットが1か0か分かれば、一意に\(j\)の値を特定できる。
\(N\)が2の累乗ちょうどのとき、最上位のビットだけは走査されない。
これにより、番号\(N\)のジュースだけが誰にもふるまわれないことになる。
例えば\(N=8\)のときは、番号8(2進法で1000)のジュースだけが誰にもふるまわれない。
しかしこれも、「誰も腹を壊さない平和な状況だった」という結果に対応するのは、誰にもふるまわれていないジュースが腐っている場合だけである。その他のジュースが腐っていた場合は、\(N\)が2の累乗でない場合と同様に区別ができる。
よって、確かにこの時には、先の分け方で問題なく区別ができることが分かった。

後は指定されているように出力するよう、実装すればよい。
実装例は以下の通り。時間計算量は\(O(N\log_{}{N})\)で、制約下において十分高速であり、勿論いつでも正しい答えを返す。

def human(n):
    res = 1
    while not(2 ** (res - 1) < n <= 2 ** res):
        res += 1
    return res

N = int(input())

M = human(N)
print(M)

for m in range(M):
    juices = []
    for i in range(1, N + 1):
        if i & (2 ** m) != 0:
            juices.append(i)
    print(len(juices), *juices)

S = input()

X = 0
for m in range(M):
    if S[m] == '1':
        X += 2 ** m

if X == 0:
    X = 2 ** M
print(X)
