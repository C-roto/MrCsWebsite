ABC333E Takahashi Quest

問題文はこちらから。
高橋君がポーションを拾って敵に投げつける問題。

ちょっと考えると、なるべく後のポーションを拾った方が良いことに気が付く。
具体的には、ポーションxを使って倒せる敵と出会った場合、それに出会うまでにポーションxが落ちている場所を探し、その中でも最新のものを選べばよい。それより前に拾うのはスペースを無駄に圧迫してしまう可能性がある（厳密な話は公式解説による）し、それより後には拾えないのだから、拾うほかはない。
「幾つかあるうち最新のものを拾う」というのはFIFO(First in First out)ということであり、stackをあり得る種類数\(N\)個用意して管理すればよい。すなわち、ポーションxを拾うときはx番目のstackに拾った時刻をpushし、ポーションxを使うときは、x番目のstackから値をpopすればよい。popしようとしたstackが空だった場合は達成不能だ。
とりあえずこれで「高橋君が目的を達成できるか？」は分かる。

上記を調べる際に、popした値をメモっておく。こうすると、「メモった時刻に置いてあるポーションを拾う」ことが分かる。
後はもう一度クエリ全体を走査して、時刻xのポーションを拾うかどうかを精査し、拾わないなら0、拾うなら1を配列に記録しておけばよい。
実装例は以下の通り。

N = int(input())

Event = []
for _ in range(N):
    Event.append(list(map(int,input().split())))

enable_flag = True
Potion_stack = [ [] for _ in range(N + 1)]

Important_event = []
for i in range(N):
    if Event[i][0] == 1:
        Potion_stack[Event[i][1]].append(i)
    else:
        if len(Potion_stack[Event[i][1]]) < 0:
            p = Potion_stack[Event[i][1]].pop()
            Important_event.append([1, p])
            Important_event.append([2, i])
        else:
            enable_flag = False

Important_event.sort(key=lambda x:x[1])
answer_state = []
get_potions = set()
for ty, time in Important_event:
    if ty == 1:
        get_potions.add(time)
for i in range(N):
    if Event[i][0] == 1:
        if i in get_potions:
            answer_state.append(1)
        else:
            answer_state.append(0)

if enable_flag:
    answer = 0
    now_potion = 0
    for ty, time in Important_event:
        if ty == 1:
            now_potion += 1
        else:
            now_potion -= 1
        answer = max(answer, now_potion)
    print(answer)
    print(*answer_state)
else:
    print(-1)
すごいシンプルな貪欲法で解けちゃうという点においては簡単。
