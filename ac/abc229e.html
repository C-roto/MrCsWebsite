ABC229E Graph Destruction

問題文はこちらから。
グラフの辺を消していき、連結成分の個数を逐次答える問題。

前から順に考えていくと非常に面倒なことになる。
最初にいくつの連結成分があるのか、それが操作によって減るのか増えるのか（消し方によってはどっちもあり得る）というのは正直無理。
その点、後ろから考えていく方が簡単だ。絶対に最後の頂点が消えれば連結成分は0だし、そこから遡る方が楽そうに思える。
そして、「頂点を消す」操作は逆転させると「頂点を増やす」操作に変わる。頂点を増やして連結成分を考える……それはUnion-Findの仕事だろう。
Union-Findの自己ライブラリに連結成分数を示す(self.groupnumber)を作っておき、以下のようにすればよい。
・頂点を増やすたび、連結成分のカウントを1増やす。
・Union操作でまだ未併合な2頂点同士を併合するたび、連結成分のカウントを1減らす。
連結成分が増減するタイミングはこれしかないので、この操作だけを考えればそれで正当だ。
ただし、「まだその時点で存在していない頂点」(=頂点pが増えたときに、p-1以下の頂点)は無視するように調整がいる。
全ての辺を走査しても、高々辺の数の2倍しか時間はかからないのでそんなに困らない。
全体的に時間計算量\(O(N + M)\)前後で実行できるプログラムが実装できるはずだ。

実装例は以下の通り(厳密な時間計算量は逆アッカーマン関数を\(\alpha(x)\)としたときに、\(O((N + M)\alpha(N))になる\))。

class DisjointSetUnionfind:
    def __init__(self, N: int):
        self.number = N
        self.parent = [ -1 for _ in range(N)]
        self.size = [ 1 for _ in range(N)]
        self.groupnumber = 0

    def find(self, v : int):
        compress = []
        while self.parent[v] != -1:
            compress.append(v)
            v = self.parent[v]
        for c in compress:
            self.parent[c] = v
        return v

    def union(self, u: int, v: int):
        ru = self.find(u)
        rv = self.find(v)
        if ru != rv:
            if self.size[ru] < self.size[rv]:
                ru, rv = rv, ru
            self.groupnumber -= 1
            self.parent[rv] = ru
            self.size[ru] += self.size[rv]

    def same(self, u: int, v: int):
        return self.find(u) == self.find(v)

N, M = list(map(int,input().split()))
G = [ set() for _ in range(N)]
for _ in range(M):
    a, b = list(map(int,input().split()))
    a -= 1
    b -= 1
    G[a].add(b)
    G[b].add(a)

uf = DisjointSetUnionfind(N)

answer = [ 0 for _ in range(N)]
for i in range(N - 1, 0, -1):
    uf.groupnumber += 1
    for p in G[i]:
        if i < p:
            uf.union(i, p)
    answer[i - 1] = uf.groupnumber

for i in range(N):
    print(answer[i])
典型と言えば典型。Union-Findを使う「頂点を消す」問題は、逆転して「頂点を増やす」操作にすると楽！
