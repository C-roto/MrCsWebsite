ABC147C HonestOrUnkind2

問題文はこちらから。
正直者と不親切者がいるなかで、正直者があり得る最大人数を求める問題。

制約が小さいのでビット全探索すれば事足りる。
「不親切な人」の扱いに一瞬困るが、要するに発言が正直でも嘘でもいいということは、その人の発言の内容を完全に無視しても良いということになるので、次のような方針が妥当になる。
・各人に正直者と不親切な人のいずれかの属性を割り振る
・正直者属性を割り振った人の発言のみ見て、矛盾がないか確かめる
これをあり得る属性の割り振り方の分だけ回せばおしまい。
全体の時間計算量は\(O(N \cdot 2^N\))程度で収まり、これは充分に高速である。
実装例は以下の通り。

N = int(input())
Cnum = []
Clame = []
for i in range(N):
    A = int(input())
    tmp = []
    for j in range(A):
        tmp.append(list(map(int,input().split())))
    Cnum.append(A)
    Clame.append(tmp)

answer = 0
for i in range(2 ** N):
    trueman_num = 0
    # 0は真偽不明、1は正直
    Condition = [ -1 for _ in range(N)]
    for j in range(N):
        Condition[j] = (i >> j) & 1

    ok_flag = True
    for j in range(N):
        if Condition[j] == 0:
            continue
        trueman_num += 1
        for k in range(Cnum[j]):
            if Clame[j][k][1] != Condition[Clame[j][k][0] - 1]:
                ok_flag = False

    if ok_flag:
        answer = max(answer, trueman_num)

print(answer)
簡単な問題だけに実装事故しないようにしたいね。
