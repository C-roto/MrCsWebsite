ABC475D Alphametic Prime

問題文はこちらから。
与えられた文字列とある意味で「同型」な素数を探す問題。

\(10^7\)以下の素数を毎回全列挙するのにそんなに時間はかかるまい。何せ664579個しかないのだから。
というわけで、\(10^7\)以下の素数をすべて列挙し、それらの素数に対して文字列との比較を行って条件を満たすものを探せばよい。
文字列比較については、以下のような論理で変形を行うことを考える。2つの命題A,Bを以下のように定義する（len(S)=len(T)とする）。
任意の整数\(1 \leqq i < j \leqq |S|\)について、
A:\(S_i = S_j\)である。
B:\(T_i = T_j\)である。
AとBが同値であるということは「AならばB、かつBならばA」が成り立っているということである。
これは「AでないまたはBである、かつ、BでないまたはAである」ということであり、これの否定についてド・モルガンの法則で変形したものを判定に使えばよい。
あとは判定すべき素数すべてについて、すべてのi,jについて上記の判定を行えばいいから、判定すべき素数の個数を\(P\)として、全体の時間計算量は\(O(P|S|^2)\)程度であり、これは制約下においては十分高速だろう。
実装例は以下の通り。

def primes(x):
    isprime = [ True for _ in range(x + 1)]
    isprime[0] = False
    isprime[1] = False
    for i in range(2, x + 1):
        if isprime[i]:
            for j in range(2 * i, x + 1, i):
                isprime[j] = False
    res = list()
    for i in range(x + 1):
        if isprime[i]:
            res.append(str(i))
    return res

S = input()
N = len(S)
P = primes(10 ** 7)

answer = '-1'
for t in P:
    if len(t) != N:
        continue
    ok_flag = True
    for i in range(N):
        for j in range(i, N):
            if ((S[i] != S[j]) and (t[i] == t[j])) or ((t[i] != t[j] and (S[i] == S[j]))):
                ok_flag = False
    if ok_flag:
        answer = t

print(answer)
