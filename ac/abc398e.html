ABC398E Tree Game

問題文はこちらから。
奇閉路ができないようにグラフに対して辺を追加していく問題。

インタラクティブジャッジの問題。ものによっては正当の検証がしにくく困るが、今回の問題はそれほどでもない。
まず、あるグラフに奇閉路が存在しないというのは、そのグラフが二部グラフであることと同値である。よって、ある頂点を始点として頂点を白と黒に塗り分けておき、同色の頂点が接しない状態を保ちながら辺を増やし続けることを考えればよい。
ある塗り分け方について、同色同士が接するように辺を引いてしまうと、奇閉路ができることは明らかなので、最初に適当に塗り分け方を決めて、それの上で考えれば問題ない。
今回頂点の数が少ないため、2頂点間を全探索して「この頂点同士は結べるか？」を調べることは容易い。また、二部グラフである状態を保ちながら辺を追加する限り、どの辺をどんな順番で追加したとしても、それが原因で引けなくなる辺は生まれない。
よって、先に辺を引ける箇所の候補をすべてピックアップしておき、引ける限り引いていくという戦略で問題ない。候補箇所の個数が偶数個なら後手を選び、奇数個なら先手を選べば、引ける辺の候補が無くなったタイミングでちょうど相手の手番に回るので必勝である。
全体では頂点間の全探索がネックになり、時間計算量は\(O(N^2)\)程度で収まり、これは充分に高速である。
実装例は以下の通り。

import collections

N = int(input())
G = [ set() for _ in range(N)]
for _ in range(N - 1):
    u, v = list(map(int,input().split()))
    u -= 1
    v -= 1
    G[u].add(v)
    G[v].add(u)

Color = [ -1 for _ in range(N)]
Color[0] = 0

que = collections.deque([0])
while que:
    p = que.popleft()
    for q in G[p]:
        if Color[q] == -1:
            Color[q] = (Color[p] + 1) % 2
            que.append(q)

Edges = set()
for p in range(N):
    for q in range(p + 1, N):
        if Color[p] != Color[q] and q not in G[p]:
            Edges.add((p, q))

if len(Edges) % 2 == 0:
    print("Second")
else:
    print("First")
    p, q = Edges.pop()
    print(p + 1, q + 1)

while Edges:
    s, t = list(map(int,input().split()))
    Edges.discard((s - 1, t - 1))
    p, q = Edges.pop()
    print(p + 1, q + 1)

win, lose = list(map(int,input().split()))
