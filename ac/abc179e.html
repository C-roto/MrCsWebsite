ABC179E Sequence Sum

問題文はこちらから。
数列の和を求める問題。

前提条件から、鳩の巣原理によって数列の\(1\)項目から\(M + 1\)項目までの間には同じ値の項が存在する。
同じ値になっている2つの項であって、数列の中で最初に現れるものを\(a_x,a_y(i < j)\)とする。
するとこの問題は\(\sum_{i=1}^{x - 1} A_i + ((N - x) \div (y - xの商)) \cdot \sum_{i=x}{y - 1} A_i + \sum_{i=x}{x + ((N - x) \div (y - x) のあまり) - 1} A_i\)を求める問題になる（空和は0とする）。
ってわけで、それを愚直に求めるコードを書けばとりあえず通る。
実装例は以下の通り。

N, X, M = list(map(int,input().split()))

R = dict()
I = []

a = X
I.append(a)
R[a] = 0
x, y = -1, -1
for i in range(1, M + 1):
    a = (a ** 2) % M
    if a not in R:
        R[a] = i
        I.append(a)
    else:
        I.append(a)
        x, y = R[a], i
        break

if N - 1 < x:
    print(sum(I[0 : N]))
else:
    D = sum(I[0 : x])
    L = sum(I[x : y])
    S = (N - x) // (y - x)
    Re = (N - x) % (y - x)
    print(D + L * S + sum(I[x : x + Re]))
割り算が苦手なので、添え字を間違えまくってバグりまくった。
こーいうの良くない！ 頑張んなきゃ！
