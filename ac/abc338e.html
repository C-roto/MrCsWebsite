ABC338E Chords

問題文はこちらから。
円の上の弦同士に交点が存在するかを考える問題。

ペアとなっている頂点同士に同じ番号を振る。
弦\(A_1B_1\)と弦\(A_2B_2\)が交点を持つとき、点\(A_2\)と点\(B_2\)は弦\(A_1B_1\)を挟んで円周の反対側にある。
これは、頂点番号が小さい順から時計回りに点を見ていったとき、点\(A_1\)と点\(B_1\)の間に点\(A_2\)もしくは\(B_2\)のいずれか片方だけがある、ということに等しい。
ある2弦が交点を持つことと、そのようになる点同士がある子とは同値なので、そのような点の存在をチェックしていけばよい。
これはスタックを使うことで管理できる。
頂点1から順にその頂点のペア番号をスタックに積んでいく。
積んでいく途中で最後尾のペア番号と今積もうとしているペア番号が同じなら、積まずに最後尾の値を削除する。
これを繰り返して、すべてのペアが消えた場合は交点なし、残ったペアがあれば交点あり、とすればよい。
\(2N\)個の点にペア番号を振り、1度ずつ見れば事足りるから、時間計算量は\(O(N)\)で抑えられ、この制約下であれば十分に高速である。
実装例は以下の通り。

N = int(input())
S = [ -1 for _ in range(2 * N)]
for i in range(N):
    a, b = list(map(int,input().split()))
    a -= 1
    b -= 1
    S[a] = i
    S[b] = i

D = set()
stack = []
for i in range(2 * N):
    if stack and stack[-1] == S[i]:
        stack.pop()
    else:
        stack.append(S[i])

if len(stack) > 0:
    print('Yes')
else:
    print('No')
