ABC471D Chargers

問題文はこちらから。
充電器にバッテリ差したり抜いたりする問題。

バッテリーを抜くときに、最大まで充電されていることが確定するバッテリーが持つ性質を考える。
クエリ全体において\(i\)番目に差すバッテリーを\(B_i\)とし、差し込み時刻を\(in_i\)、差し込み時点の充電量を\(w_i\)としよう。
クエリ全体において\(j\)番目にバッテリーを抜くときの抜く時刻を\(out_j\)と書くとすると、この時抜かれるバッテリーの充電量は、既に差されていてまだ抜かれていないバッテリーであって、\(w_i + (out_j - in_i)\)の値が最大となるような\(B_i\)である。
これは\(out_j\)の値に関係なく、\(w_i - in_i\)の値が最大であるものを引っこ抜いて来ればよい、と言っているに等しい。
よって、バッテリーを差すタイミングで\(w_i - in_i\)の値を何らかのデータ構造に格納しておき、抜くタイミングでそのデータ構造の中から最大の値を引っ張り出して\(out_j\)の値を足せばよい。勿論、バッテリーの最大容量を超えていた場合は、バッテリーの最大容量の方を出力する必要がある。そのデータ構造の中に値が入っていなければ、-1を出力する。
これは優先度付きキューを使えば実現できる(Pythonならheapqを使えばいいね)。
時間計算量についてはクエリ回数と優先度付きキューを操作する回数を考慮して、\(O(Q\log_{}{Q})\)程度で抑えられるだろう。勿論この制約なら充分高速である。
実装例は以下の通り。

import heapq

Q, V = list(map(int,input().split()))
HQ = []
hqsize = 0
heapq.heapify(HQ)

for q in range(Q):
  query = list(map(int,input().split()))
  if query[0] == 1:
    heapq.heappush(HQ, -1 * (query[2] - query[1]))
    hqsize += 1
  else:
    if hqsize == 0:
      print(-1)
      continue
    p = heapq.heappop(HQ)
    print(min(query[1] - p, V))
    hqsize -= 1
簡単ではあるけど、良い感じに考えるのが大事。
