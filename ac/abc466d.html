ABC466D Placing Rooks

問題文はこちらから。
チェスの盤面の指定された箇所にルークを置く問題。

現代だと類題も多いような気がする。
配列Row_to_colmunを用意し、Row_to_colmun[i]の値が「i行目のコマが置かれている列」を示すようにする。同様に配列Colmun_to_rowを用意する(実装例ではR_d,C_dという名前になっている)。
そして、新しいコマが置かれるたびに
・今置こうとしている行\(i\)について、既に行\(i\)にコマが置かれている場合、列Row_to_colmun[i]に置かれているコマも除く
といった操作をすれば、盤面に置かれているコマが正しく管理できる。
問題の制約から、各行と各列について、その行/列には高々1つしかコマが置かれていないためにこうした解き方が成立する。
実装例は以下の通り。時間計算量は\(O(N+M)\)になる。

N, M = list(map(int,input().split()))
R = [ 0 for _ in range(M)]
C = [ 0 for _ in range(M)]
for i in range(M):
    R[i], C[i] = list(map(int,input().split()))

# R_d[r]は行rに存在するコマが列R_d[r]に存在することを示す
R_d = [ -1 for _ in range(N + 1)]
# C_d[c]は列cに存在するコマが行C_d[c]に存在することを示す
C_d = [ -1 for _ in range(N + 1)]
# 上記2つとも、-1はコマが置かれていないことを示す。

for i in range(M):
    if R_d[R[i]] != -1:
        C_d[R_d[R[i]]] = -1
    if C_d[C[i]] != -1:
        R_d[C_d[C[i]]] = -1
    R_d[R[i]] = C[i]
    C_d[C[i]] = R[i]

answer = 0
for i in range(1, N + 1):
    if R_d[i] != -1:
        answer += 1

print(answer)
難易度がぶれやすいD問題らしいという感じ。
未参加の回だけど、茶～緑レート帯だとこの回は早解きがものを言ったんじゃないだろうか（AtcoderProblemsによれば、E問題はそれなりに難しそうという感じだし）。
\(N\)の制約によっては工夫が要りそうだが、今回は素直に言われた通りの管理でよさそう。
