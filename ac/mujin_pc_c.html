MUJINプログラミングチャレンジ C オレンジグラフ

問題文はこちらから。
辺をオレンジ色に着色していき、オレンジ色のみでできた奇閉路が完成しないようにする方法の数を答える問題。

奇閉路といえば二部グラフ。
というわけで、限界まで操作を行ったグラフは、オレンジの辺について2部グラフに少なくともなっているはずである。
なので、すべての頂点を白もしくは黒のいずれかに塗り分け、両端点の色が違う辺だけを貪欲に取っていくことを考える。辺を取る順番によって取れなくなる辺はないので、頂点の塗り分け方1つにつき必ずただ1つだけ「両端点の色が違う辺をすべて、かつそれに限りオレンジ色に塗ったグラフ」ができる。このようなグラフを、その塗り分け方に対する「極大にオレンジなグラフ」と呼ぶことにしよう。
もう少し形式的には、\(N\)ビットのビット列\(X\)があって、\(X\)の下\(i(i=1,2,...N)\)桁目が0のとき頂点\(i\)を白色に、1のとき黒色に塗り分けるとしたとき、各\(N\)ビットのビット列たちは、それぞれに固有の頂点の塗り分け方と対応していると見ることができる。
その各ビット列に対して、ただ1つ極大にオレンジなグラフが定まる。極大にオレンジなグラフ全体の集合を\(M\)とする。

さて、問題の条件を満たすように限界まで操作を行ったグラフは、\(M\)の元である。
限界まで操作を行ったグラフは、オレンジの辺に関して二部グラフとなっていることは最初に確認した通りである。ここで、もしこのグラフが\(M\)の元でないとすると、(同色両端点の辺を結んでいない以上)両端点の色が違うのにオレンジ色に塗られていない辺があり、「両端点が違うのにオレンジではない辺」が存在するので矛盾。よって、限界まで操作を行ったグラフである、という仮定に矛盾する。

また、\(M\)の元であってオレンジの辺について連結であるものは、限界まで操作を行ったグラフである。
まず、\(M\)の元はその辺の塗り方から、オレンジの辺についての二部グラフなので、問題文の条件を満たすように塗り分けているものである。ここで、このグラフはオレンジの辺について連結なグラフであることから、各頂点の彩色はすべて反転させるものを除き一意に定まっていることに注意する。
もしこのグラフについてこれ以上操作ができると仮定すると、操作後も二部グラフであるから、新しく結んだ2頂点は互いに異なる色である。すると、これは\(M\)の元を選ぶ時点で両端点が違う辺をすべてオレンジ色で塗ったという仮定に反する。

加えて、極大にオレンジなグラフであって連結でないものは、問題文の条件を満たさない（つまり、まだ奇閉路を加えないように着色操作が可能である）。
これは元のグラフが連結であることから直ちに従う。つまり、非連結な極大にオレンジなグラフの、2つの互いに素な連結成分の間には元のグラフの間に辺があり、これ1本だけをくっつけても奇閉路はおろか閉路もできない。よって、まだオレンジに塗ることができる辺があることになる。

以上の考察より、\(M\)の元であって連結なものの集合と、問題文の操作を限界まで行ったグラフの集合は一致する。
よって、\(M\)の元であって連結なものの集合を求めればよい。
これは各頂点の塗り分け方に対して、極大にオレンジなグラフを構成し、それが連結であるかどうかを見て、連結であれば選んだ辺の集合をメモしておく。
最終的にメモされた、相異なる選んだ辺の集合の個数が求める答えである。
実装例は以下の通り。

class DisjointSetUnion:
    def __init__(self, N: int):
        self.number = N
        self.parent = [ -1 for _ in range(N)]
        self.size = [ 1 for _ in range(N)]

    def find(self, v : int):
        compress = []
        while self.parent[v] != -1:
            compress.append(v)
            v = self.parent[v]
        for c in compress:
            self.parent[c] = v
        return v

    def union(self, u: int, v: int):
        ru = self.find(u)
        rv = self.find(v)
        if ru != rv:
            if self.size[ru] < self.size[rv]:
                ru, rv = rv, ru
            self.parent[rv] = ru
            self.size[ru] += self.size[rv]

    def same(self, u: int, v: int):
        return self.find(u) == self.find(v)

def max_biparete(state, edges):
    res = []
    for p, q, n in edges:
        if ((state >> p) & 1) ^ ((state >> q) & 1) == 1:
            res.append(n)
    return tuple(res)

N, M = list(map(int,input().split()))
Edges = []
for i in range(M):
    a, b = list(map(int,input().split()))
    a -= 1
    b -= 1
    Edges.append((a, b, i))

answer = set()
for i in range(2 ** N):
    t = max_biparete(i, Edges)
    uf = DisjointSetUnion(N)
    renketsu = 0
    for i in t:
        p, q, x = Edges[i]
        if not(uf.same(p, q)):
            uf.union(p, q)
            renketsu += 1
    # 連結な二部グラフになることと、操作がこれ以上できないことは同値
    if renketsu == N - 1:
        answer.add(t)
print(len(answer))
