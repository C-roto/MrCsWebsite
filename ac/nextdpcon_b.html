問題文はこちらから。
閉路のない単純有向グラフ上のパスの個数を求める問題。

頂点1から行ける頂点に行き、そこから次々と行ける頂点を調べていく……という方法がベースであることはすぐにわかる。
一方で、どの頂点から調べるかというのは重要な関心ごとで、例えば以下のようなテストケースが与えられた時を考えてみよう。
5 6
1 2
1 3
1 4
2 3
3 5
4 5
この時、1から直接遷移できる頂点は2,3,4があるが、うっかり3からパスを数え始めると、2から3へ流れ込んでくるパスをうまくカウントできずWAする可能性が高い。
なので、「もう他に流れ込んでくるパスがない」という条件を満たす中で調べられる頂点を調べるのがよい。
そこで、この問題ではトポロジカルソートを行う必要がある。トポロジカル順に並び替えれば、その順に調べることで、「後から実はパスが流れ込んでくる可能性がありました」という状況をなくすことができる。
トポロジカルソートにかかる時間計算量が\(O(N+M)\)で、ソート後のdpも時間計算量\(O(N+M)\)なので、全体としても時間計算量\(O(N+M)\)で計算でき、これは十分高速である。
実装例は以下の通り。


mod = 998244353
T = int(input())

for t in range(T):
    N, M = list(map(int,input().split()))
    G = [ list() for _ in range(N)]
    indeg = [ 0 for _ in range(N)]
    for i in range(M):
        u, v = list(map(int,input().split()))
        u -= 1
        v -= 1
        indeg[v] += 1
        G[u].append(v)
    
    dp = [ 0 for _ in range(N)]
    dp[0] = 1
    t_sorted = []

    stack = []
    for i in range(N):
        if indeg[i] == 0:
            stack.append(i)
    
    while stack:
        p = stack.pop()
        t_sorted.append(p)
        for q in G[p]:
            indeg[q] -= 1
            if indeg[q] == 0:
                stack.append(q)
    
    for p in t_sorted:
        for q in G[p]:
            dp[q] += dp[p]
    
    print(dp[N - 1] % mod)
単なる数え上げに一ひねり加わった問題。
DPの基本テクニックを知ってるから解けるというより、DPだと知ったうえで何をしたいからどういう手順を踏みたいか考察することが重要なように思えた。
