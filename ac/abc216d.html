ABC216D Pair of Balls

問題文はこちらから。 筒に入れたボールをペアにして上から取り出していく問題。

筒の一番上に入っているボールを毎回走査していると、時間計算量の見積もりは\(O(M \cdot max(k))\)あたりになり、間に合うとは言い切れなくなる。
計算の無駄を減らすなら、可能な限り1度見たボールを見ずとも判断できるように工夫をしたい。
今回の問題の制約なら、あるペアを取り出すことができるのなら、いつでも取り出してよい（=取り出したことが原因で損をしない）ことが容易にわかる。
あるペアを取り出さずに取り出せる他のすべてのペアは、そのペアを取り出したとしてもすべて取り出せるからだ。
よって、取り出せるペアを見つけ次第取り出していくような仕組みを考えればよい。

今回は次のような実装方針が適切だろう。
・キューを用意し、今筒の最上部に入っているすべてのボールを詰める。
・キューから1つずつボールを取り出す。
→取り出したボールと同じ色のボールが場になければ、そのボールを場に出す。
→あれば、当該の色の置いてあるボールと取り出したボールを両方消して、各ボールの入っていた筒の次のボールをキューに詰める。
こうすることで、キューと場に出ているボールは、あるタイミングにおける筒の最上部に入っているボールたちの集合になっている。
また、同じ色のボールがあったときに必ず見つけて消せることも明らかだ。
この方針ならば、すべてのボールは高々1回以下の回数キューに詰めまれ、ほかの計算は定数時間でできると考えられるから、全体の時間計算量は\(O(N + M)\)で抑えることができ、今回の制約下では十分に高速である。
実装方針は以下の通り。

import collections

N, M = list(map(int,input().split()))
Balls = []
lenBalls = []
for i in range(M):
    lenBalls.append(int(input()))
    Balls.append(list(map(int,input().split())))

que = collections.deque()
for i in range(M):
    que.append([Balls[i][0], i, 0])

counter = 0
catched = dict()
while que:
    p, b, t = que.popleft()
    if p not in catched:
        catched[p] = (b, t)
    else:
        c, s = catched[p]
        if lenBalls[c] - 1 > s:
            que.append([Balls[c][s + 1], c, s + 1])
        if lenBalls[b] - 1 > t:
            que.append([Balls[b][t + 1], b, t + 1])
        catched.pop(p)
        counter += 1

if counter < N:
    print('No')
else:
    print('Yes')
こういう問題こそ「ボールを見る回数をなるべく減らして高速化したい」みたいな発想がキーになる感じがある。
