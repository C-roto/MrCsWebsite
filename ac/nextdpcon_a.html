Next DP Contest A ポリオミノ

問題文はこちらから。
ポリオミノの敷き詰めを動的計画法にて考える問題。

僕が競プロを始める遥か前に、Typical DP Contest、DP まとめコンテストというコンテストが開催された。
名の通り、動的計画法について学ぶための有志コンテストだったそうだが、此度それに続くコンテストが行われた（と説明を読む限りでは理解できる）。
今回はそんなNext DP ContestのA問題を取り上げてみる。

ポリオミノの敷き詰めは大学入試でもよく見たことのある題材ではなかろうか。東大が大昔に漸化式を組ませて解かせてた気がする。
漸化式を書く時にも大事なことだが、あり得る遷移条件を斬り分けて考えることが大切だ。
今回だと、自分は以下の3つに分けて考えた。
・左から\(N\)マス目の上下がともに埋まっている埋め方の数を\(perf_{N}\)とする。
・左から\(N\)マス目の上だけが埋まっていない埋め方の数を\(ubroke_{N}\)とする。
・左から\(N\)マス目の下だけが埋まっていない埋め方の数を\(dbroke_{N}\)とする。
こうすると、\(i \geqq 3\)において遷移は以下のように書ける。
・\(perf_{i} = perf_{i - 2} + perf_{i - 1} + dbroken_{i - 1} + ubroken_{i - 1}\)
(長方形ポリオミノを横に倒して2つ使う、長方形ポリオミノを縦に1つだけ使う、下の欠けたL字にL字を嵌める、上の欠けたL字にL字を嵌める)
・\(ubroken_{i} = perf_{i - 2} + dbroken_{i - 1}\)
(上の欠けたL字を使う、下の欠けたL字に横倒しのポリオミノを1つだけ使う)
・\(dbroken_{i} = perf_{i - 2} + ubroken_{i - 1}\)
(下の欠けたL字を使う、上の欠けたL字に横倒しのポリオミノを1つだけ使う)
後は適切に初期化してこの遷移を愚直に計算すればよい。\(N \leqq 40\)程度なら答えも大した大きさにならないので各部の計算はほぼ定数時間と見なせ、全体の時間計算量は\(O(N)\)程度で処理できる。
実装例は以下の通り。

N = int(input())

dp_perf = [ 0 for _ in range(N + 1)]
dp_u_broken = [ 0 for _ in range(N + 1)]
dp_d_broken = [ 0 for _ in range(N + 1)]

dp_perf[0] = 1

for i in range(1, N + 1):
    dp_perf[i] += dp_perf[i - 2] + dp_perf[i - 1] + dp_d_broken[i - 1] + dp_u_broken[i - 1]
    dp_u_broken[i] += dp_perf[i - 2] + dp_d_broken[i - 1]
    dp_d_broken[i] += dp_perf[i - 2] + dp_u_broken[i - 1]

print(dp_perf[N])
漸化式をある程度整理すると、数列\(perf\)についてのみのシンプルな漸化式を得ることができ、以下のようなコードでも通る。

N = int(input())

dp_perf = [ 0 for _ in range(40 + 1)]
dp_sum = 2

dp_perf[0] = 1
dp_perf[1] = 1

for i in range(2, N + 1):
    dp_perf[i] = 2 * dp_sum - (dp_perf[i - 1] + dp_perf[i - 2])
    dp_sum += dp_perf[i]

print(dp_perf[N])
なんか、A問題という割には意外と考えることあって大変じゃない？
