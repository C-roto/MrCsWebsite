ABC320E Somen Nagashi

問題文はこちら。 そうめん流しのイベントで、各人が得るそうめんの量を考える問題。

時間とともに経過を考える問題はイベントソートとか様々なやり方がある。
今回は優先度付きキューに入れて取り出すという方法を取ることにする。
こうすれば、そうめんを受け取るイベントと人が戻ってくるイベントを同列に扱うことができ、処理が楽になる。
戻ってきたタイミングで列には戻っている扱いなので、同時刻に2種類のイベントが発生した時は列に戻ってくる方を優先するようにする（実装例の中で、戻ってくる側のイベントのqを-1に設定してるのはそういう意図）。

あとは今先頭に並んでいる人の番号だが、これはPythonならSortedSetなどを使えば高速に処理可能である。
SortedSetが空(=列に誰もいない)でない限り、そのとき先頭にいる人はSortedSetの0番目にいる人なので、それを取得すればよい。
で、その人に対するそうめんの取得処理が終わったらその人をSortedSetから一時的に削除して、s秒後に追加イベントを発生させるようにすればよい。

各そうめん追加イベントに対し、人が戻ってくるイベントも同数発生しうるが、せいぜいMの定数倍で抑えられる。
実装例は以下の通り。

import heapq
import sortedcontainers

N, M = list(map(int,input().split()))
Somen = [ 0 for _ in range(N)]
lined = sortedcontainers.SortedSet([i for i in range(N)])

HQ = []
heapq.heapify(HQ)

for i in range(M):
    T, W, S = list(map(int,input().split()))
    heapq.heappush(HQ, (T, 0, W, S))

while HQ:
    t, q, w, s = heapq.heappop(HQ)
    if q == 0:
        if len(lined) == 0:
            continue
        top = lined[0]
        Somen[top] += w
        lined.discard(top)
        heapq.heappush(HQ, (t + s, -1, top, -1))
    else:
        lined.add(w)

for i in range(N):
    print(Somen[i])
初め実装した時はtopを別に保持しておいていたが、よく考えるとgetが\(O(\log_{}{N})\)で出来るなら別に問題ないということに、指摘を受けて気が付いた。
そういうわけで毎回列の先頭を取得しに行くようにしたらバグらなくなった。
要らない変数は増やさないようにしよう。その変数、本当に必要ですか？ の精神を持ちたい。
