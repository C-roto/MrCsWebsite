ABC176D Wizard in Maze

問題文はこちらから。
なるべく少ないワープで迷路を脱出する問題。

移動回数ではなくワープ回数を問われているというのがミソ。
つまり、相互に行き来できるマスは同一のマスとみなしてひとまとめにしてもよい。
もう少ししっかりした言葉で方針を固める。
各道(グラフの意味でのpathではなくて、問題で与えられている「道」のこと)を頂点とし、隣接する移動可能な道同士の間に辺を張ったグラフGを考える。このグラフにおいて、同じ連結成分に属する各頂点同士は通常の移動で相互に行き来可能あるし、異なる連結成分同士に属する各頂点同士は通常の移動では相互に行き来不可能である。
そこで、グラフGの各連結成分を1つの頂点とみなし、「連結成分Aに所属するあるマスXから、別の連結成分Bに所属するあるマスYへワープで移動可能である」という条件を満たすような連結成分A,B同士の間に辺を張ったグラフHを考える。
このとき、グラフHにおいて「スタートの道が属する連結成分に対応する頂点」から「ゴールの道が属する連結成分に対応する頂点」まで移動するために通る最小の辺の本数（＝使うワープの回数）が求める答えになる。
後はグラフGを構築して連結成分同士に分け（Union-findでも良いだろうし、実装例では未調査の各マスからBFSをして求めている）、グラフHを構築して、グラフH上でBFSすれば答えが求まる。
全体の時間計算量は各道からワープ可能な道を調べるところで、調べるマス数を\(n_c(=25)\)としたとき、\(O(HWn_c)\)程度で押さえられ、制約下においてはギリ高速と言えそうだ。
実装例は以下の通り。

import collections

def is_in(h, w):
    return 0 <= h <= H - 1 and 0 <= w <= W - 1

def warp(h, w):
    fro = parents[h][w]
    to = set()
    for i in range(-2, 2 + 1):
        for j in range(-2, 2 + 1):
            if is_in(h + i, w + j) and S[h + i][w + j] == ".":
                to.add(parents[h + i][w + j])
    return fro, to

H, W = list(map(int,input().split()))
C_h, C_w = list(map(int,input().split()))
C_h -= 1
C_w -= 1
D_h, D_w = list(map(int,input().split()))
D_h -= 1
D_w -= 1

S = []
for i in range(H):
    S.append(list(input()))

m_1 = [1, -1, 0, 0]
m_2 = [0, 0, 1, -1]
parents = [ [-1 for _ in range(W)] for __ in range(H)]
idx = 0

for h in range(H):
    for w in range(W):
        if S[h][w] == "." and parents[h][w] == -1:
            parents[h][w] = idx
            que = collections.deque([(h, w)])
            while que:
                p, q = que.popleft()
                for i in range(4):
                    np = p + m_1[i]
                    nq = q + m_2[i]
                    if is_in(np, nq) and S[np][nq] == "." and parents[np][nq] == -1:
                        parents[np][nq] = idx
                        que.append([np, nq])
            idx += 1

G = [ set() for _ in range(idx)]
for h in range(H):
    for w in range(W):
        if S[h][w] == ".":
            p, t = warp(h, w)
            for s in t:
                if p != s:
                    G[p].add(s)
                    G[s].add(p)

c = parents[C_h][C_w]
d = parents[D_h][D_w]

que = collections.deque([c])
dist = [ -1 for _ in range(idx)]
dist[c] = 0
while que:
    p = que.popleft()
    for q in G[p]:
        if dist[q] == -1:
            dist[q] = dist[p] + 1
            que.append(q)

print(dist[d])
グラフの上にグラフを作って問題を解くの好き。
具体的なものを抽象的な概念にして色んなことをするというのは面白い。
