ABC190E Magical Ornament

問題文はこちらから。
魔法石を並べて良い感じの装飾を作る問題。

最終的に指定されたK個の石を繋げるには、隣り合わせにできる組を連鎖させるほかはない。
これは石を頂点、隣り合わせにできる組を辺としてグラフを描き、そのグラフ上で指定された石に対応するK個の頂点が連結かどうかを見ればよい。
また、BFSやDFSなどを使うことで、指定された石に対応するK個の頂点同士の最短距離を出すことができる（Kは充分小さいので、K回BFSをしたとて大したことにはならないはずだ）。
というわけで、指定された石に対応する各頂点同士の最短距離が求まった。
もう元のグラフは不要なので、\(K\)頂点で、\(C_i\)と\(C_j\)の間の最短距離を頂点\(i\)と頂点\(j\)間の重みとする重み付きの完全グラフ\(G\)を考える。
この問題は\(G\)のハミルトン路(閉路ではない)であって、重みが最小となるようなものを求める問題と見なすことができる。
これは『アルゴリズムイントロダクション』だと巡回セールスパーソン問題(TSP)と呼ばれていたアレに帰着できる。
\(K \leqq 17\)なる今回であれば、ヘルドカープのアルゴリズム（集合と都市番号を添え字とする動的計画法）で充分に解くことができる。
ただし、今回は巡回を目的としないのでスタートは必ず頂点1とは限らない。すべての頂点を始点として、ゴールに到達した時点の値のうち最小の値を調べればよい。
時間計算量は動的計画法の部分かBFSかがネックになって、\(O(K(N + M + K2^K))\)程度で抑えが効くだろう。無論充分高速である。
実装例は以下の通り。

import collections
import sys

def bfs(v):
    que = collections.deque([v])
    res = [ -1 for _ in range(N)]
    res[v] = 0
    while que:
        p = que.popleft()
        for q in G[p]:
            if res[q] == -1:
                res[q] = res[p] + 1
                que.append(q)
    return res

N, M = list(map(int,input().split()))

G = [ set() for _ in range(N)]
for _ in range(M):
    a, b = list(map(int,input().split()))
    a -= 1
    b -= 1
    G[a].add(b)
    G[b].add(a)

# 指定されているK個の魔法石同士の最短距離をピックアップする
K = int(input())
C = list(map(int,input().split()))
C = [ C[i] - 1 for i in range(K)]
newG = [ [ 0 for _ in range(K)] for _ in range(K)]
for i in range(K):
    R = bfs(C[i])
    for j in range(K):
        if i == j:
            continue
        newG[i][j] = R[C[j]]
        if R[C[j]] == -1:
            print(-1)
            sys.exit()

# ヘルドカープのアルゴリズムの応用。O(2^K * K^2)程度の時間で計算可能
# dp[s][v] = sに含まれる都市をすべて通ってvにいるのにかかるコスト
# 巡回が目的じゃないので、すべての点からスタートさせないとダメ
dp = [ [ 10 ** 10 for _ in range(K + 1)] for _ in range(2 ** K)]
for v in range(K):
    dp[1 << v][v] = 0

for p in range(1, 2 ** K):
    for v in range(K):
        q = p | (1 << v)
        if p == q:
            continue
        for u in range(K):
            if (p >> u) & 1 == 0:
                continue
            dp[q][v] = min(dp[q][v], dp[p][u] + newG[u][v])

# 最短距離に石1個分を足したもの
print(min(dp[-1]) + 1)
元のグラフで2点間の最短距離を求めるのが1つ。
そこから動的計画法で最短距離を求めるのがもう1つ。
1つずつのステップはそれほどでもないけれど、組み合わせて2段階あるのがちょっと難しいかも。
