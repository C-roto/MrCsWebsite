ABC178D Redistribution

問題文はこちらから。
再分配する問題。

項数が\(n\)で条件を満たす数列を考えよう。
この時、各項は3以上の整数であるから、\(S - 3n\)を\(n\)個の各項へと割り振る方法の数だけ数列は存在する。
要するに、\(S - 3n\)個の丸と\(n-1\)個の仕切りを並べる方法の数に対応して、数列も同じだけ存在する。
よって項数が\(n\)で求める数列は\(\frac{S - 2n - 1}{(S-3n)(N-1)}\)通りあるので、これを\(S - 3n\)が0以上である範囲で\(n\)を1ずつ増やしながら足し合わせればよい。

階乗の前計算とループの回数がネックで、全体の時間計算量はおよそ\(O(S + \log_{}{mod})\)程度だろうか。
いずれにせよ十分高速に計算できる。実装例は以下の通り。

S = int(input())
mod = 1000000007

p = mod - 2
fact_rev = 1
doubleing = 1
facts = [1, 1]
for i in range(2, S + 1):
    facts.append(facts[-1] * i % mod)
    doubleing *= i
    doubleing %= mod
while p != 0:
    if p & 1 == 1:
        fact_rev *= doubleing
        fact_rev %= mod
    p = p >> 1
    doubleing = doubleing ** 2
    doubleing %= mod

revs = [fact_rev]
for i in range(S, 0, -1):
    revs.append(revs[-1] * i % mod)
revs.reverse()

n = 1
answer = 0
while S - 3 * n >= 0:
    answer += (facts[S - 2 * n - 1] * revs[n - 1] * revs[S - 3 * n]) % mod
    n += 1
print(answer % mod)
