問題文はこちらから。
ある数の階乗の約数であって、約数がちょうど75個あるような数がいくつあるかを求める問題。

約数が\(75=5 \times 5 \times 3\)個ある数は、素因数分解の指数と約数の個数に関するルールから、以下のような数に絞られる。
・ある素数\(p\)を用いて\(p^{74}\)と表せる数
・相異なる素数\(p,q\)を用いて\(p^{24} q^2\)もしくは\(p^{14} q^4\)と表せる数
・互いに相異なる素数\(p,q,r\)を用いて\(p^4 q^4 r^2\)と表せる数
よって、\(N!\)の約数であって、このような数がいくつあるかを求めればよい。
まず、\(N!\)を素因数分解した結果を求める。これは1以上N以下の素因数分解の結果をそのまま合わせればよい。
次に、先のような形の素数の積で表せるような数を列挙し、すべて試していく。\(N!\)は\(N\)以下の素数しか素因数に持たないから、\(N\)以下の素数をすべて列挙してそれらについて試せばよい。
勿論実際に掛け合わせて約数になるのかチェックしていると大変なので、列挙した各素数の組に対して、その素数が\(N!\)にいくつ含まれているかを参照する形で算出する。
重複を数えないように注意して実装すれば答えが出る。実装例は以下の通り。

def proddiv_frac(n):
    res = dict()
    for i in range(1, n + 1):
        m = i
        for j in range(2, i + 1):
            if j ** 2 > i:
                break
            while m % j == 0:
                if j not in res:
                    res[j] = 1
                else:
                    res[j] += 1
                m //= j
        if m != 1:
            if m not in res:
                res[m] = 1
            else:
                res[m] += 1
    return res

def elatos(n):
    is_prime = [ True for _ in range(n + 1)]
    is_prime[0] = False
    is_prime[1] = False
    for i in range(2, n + 1):
        if is_prime[i]:
            for j in range(2 * i, n + 1, i):
                is_prime[j] = False
    res = list()
    for i in range(n + 1):
        if is_prime[i]:
            res.append(i)
    return res

N = int(input())
D = proddiv_frac(N)
P = elatos(N)

one_answer = 0
for p in P:
    if D[p] >= 74:
        one_answer += 1

two_answer = 0
for p in P:
    for q in P:
        if p == q:
            continue
        if D[p] >= 24 and D[q] >= 2:
            two_answer += 1
        if D[p] >= 4 and D[q] >= 14:
            two_answer += 1

three_answer = 0
for p in P:
    for q in P:
        for r in P:
            if p == q or q == r or r == p:
                continue
            if D[p] >= 4 and D[q] >= 4 and D[r] >= 2:
                three_answer += 1
three_answer //= 2

print(one_answer + two_answer + three_answer)
