ABC119C Synthetic Kadomatsu

問題文はこちらから。
門松を作るための竹を低いコストで作ることを考える問題。

Nが充分に小さいので、各竹をグループ分けするのを愚直にやってもそんなにかからないはず。
マージ後の竹は3つ(仮に竹X,Y,Zとする)+使わない分となっているはずなので、竹が最終的にX,Y,Z,使わないのどれに分類されるかを試しても、単純に考えて\(4^N\)通りで済む。
あとは各\(4^N\)通りに対して
・X,Y,Zのどの竹も存在しているか
・各竹を作るのにかかる合成魔法のコストの合計はどれくらいか
・X,Y,Zの長さをA,B,Cのどれに合わせるか決め、そのときに必要な延長魔法と短縮魔法の合計を出す
・すべての魔法に必要な合計コストを出す
という操作をすればよい。時間計算量は\(O(N \cdot 4^N)\)程度で抑えられる。
実装例は以下の通り。

import itertools

N, A, B, C = list(map(int,input().split()))
Banboo = []
for i in range(N):
    Banboo.append(int(input()))

# 0,1,2は竹のグループ番号、3は使わない竹
it = itertools.product([0, 1, 2, 3], repeat=N)
pattern = list(itertools.permutations([0, 1, 2]))

answer = 10 ** 30
# 竹のグループ分けと、各グループをどの長さに合わせるかを全パターン試す
for c in it:
    if not(0 in c and 1 in c and 2 in c):
        continue

    # 先に合成魔法のコストを算出する
    marge_mp = 0
    marge_count = [0, 0, 0, 0]
    marge_banboos = [0, 0, 0, 0]
    for i in range(N):
        marge_count[c[i]] += 1
        marge_banboos[c[i]] += Banboo[i]
    for i in range(3):
        marge_mp += 10 * (marge_count[i] - 1)

    # 延長魔法もしくは短縮魔法を使う合計コストを算出する
    for p, q, r in pattern:
        answer = min(answer, marge_mp + abs(A - marge_banboos[p]) + abs(B - marge_banboos[q]) + abs(C - marge_banboos[r]))

print(answer)
力任せに全部探索するっていうのは楽でよい。
