ABC477C Range Search Query

問題文はこちらから。
範囲内に指定の文字列があるかをサーチする問題。

Tのサイズがとても小さいことを利用し、各\(i=1,2,...,|S|\)について、Sの\(i\)文字目から始まる\(|T|\)文字の文字列がTと一致するかを逐一見て確認していく。
Tと一致した文字列の、始点のリストを\(A\)と終点のリストを\(B\)として、始点が前から\(j\)番目であるようなものの始点を\(A_j\)、終点を\(B_j\)としておく。

次に、各クエリにおいて与えられた\(L\)の値を\(A\)の中で二分探索し、\(L <= A_j\)となるような最小の\(j\)を見つけてくる。
もしそのような\(j\)がない場合、あらゆるTと一致する部分文字列の始点より後ろを範囲の始点に指定しているので、当然ながら範囲の中にTと一致する部分文字列は存在しない（よってNoを出力して終わり）。
\(j\)が存在した場合、この時\(B_j\)と\(R\)の大小関係によって以下の通り分析できる。
・\(B_j \leqq R\)のとき、明らかに閉区間\([L, R]\)は閉区間\([A_j, B_j]\)を含んでいる。この時、指定の範囲は\(S_{A_j}\)を始点とし\(S_{B_j}\)を終点とする、Tと一致する部分文字列を含んでいる（のでYesを出力する）。
・\(R < B_j\)のとき、少なくとも\(A_j < R < B_j = A_j + |T| - 1\)が成り立っている。\(j < k\)なる任意の\(k\)に対し、少なくとも\(R < B_j < B_k = A_k + |T| - 1\)が成り立つ。これは\(A_j\)以降を始点とするTと一致する文字列の終点が範囲からはみ出ることを表す。
始点については二分探索で選んだ都合上、\(A_j\)より小さい始点を持つTと一致する部分文字列はすべて始点が範囲からはみ出る。以上より、この範囲は条件を満たす部分文字列を含んでいない（のでNoを出力する）。

というわけで、\(A\)を二分探索する部分がネックとなり、全体の時間計算量は\(O(Q\log_{}{|S}) + |S| |T|\)程度で押さえられ、まあ高速だろう。
実装例は以下の通り。

import bisect

Q = int(input())
S = input()
T = input()

Ls = []
Rs = []
for i in range(len(S)):
    ok_flag = True
    for j in range(len(T)):
        if i + j >= len(S):
            ok_flag = False
            break
        if S[i + j] != T[j]:
            ok_flag = False
            break
    if ok_flag:
        Ls.append(i)
        Rs.append(i + j)

for _ in range(Q):
    L, R = list(map(int,input().split()))
    L -= 1
    R -= 1
    a = bisect.bisect_left(Ls, L)
    if a == len(Ls):
        print('No')
        continue
    if Rs[a] <= R:
        print('Yes')
    else:
        print('No')
