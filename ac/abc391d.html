ABC391D Gravity

問題文はこちらから。
1ブロックずつ降ってくる落ちものパズルで消えるブロックを調べる問題。

訊かれる時刻は最大\(10^9\)までなので、愚直なシミュレーションは間に合わない。
そもそも、消したり接地したりの判定を愚直にやってたら、もうちょい上限が低くても無理な気がする。
なので工夫が必要だ。今回の問題に答えようと思ったら「そもそもそのブロックは消えるのか」「あるブロックが消えるのはいつか」という問いに答えられるようにしておけばよいのであって、わざわざ1秒ごとの盤面をフルで考える必要などない。
あるブロックが消えるのは、そのブロックを含む1列が完成した瞬間である。つまり、各ブロックについて、そのブロックを含む1列が完成する時間を調べればよい。
ここで、各行についてブロックの位置関係は時間が経っても入れ替わらない（つまり、上にあるブロックほど最終的にも上にある）ことを考えると、列が\(i\)回目に揃う時刻は、各行の上から\(i\)個目のブロックであって、最後に接地するものが接地する時刻に等しくなる。
よって、各行のブロックとそれが接地する時刻を、行ごとにキューなどで管理しておくのが丸いだろう（実装例では配列で管理している）。すべてのキューに要素が1つ以上あるなら、1つずつ各キューから値をpopし、popしたブロックの番号をすべてメモし、popした時刻のうちで最も遅い時刻を保持する。
そして、連想配列にブロックの番号をkey、時刻をvalueとして、今メモしたブロックの番号1つずつのvalueを保持している時刻に更新しておく。
popできなくなるキューが生まれる=それ以上列がそろわなくなる、なのでその時点で時刻を記録できていないブロックはそれ以降絶対に揃うことはない(よって、クエリで訊かれた時点で必ずYesを返せばよい)。
時刻を記録できたブロックについては、クエリで訊かれた時刻が消える時刻より前か後かでYesかNoを切り替えればよい。
実装例は以下の通り。

N, W = list(map(int,input().split()))
Xs = [ [] for _ in range(W + 1)]
for i in range(N):
    x, y = list(map(int,input().split()))
    Xs[x].append([y, i])

shortest = 10 ** 30
for i in range(1, W + 1):
    Xs[i].sort()
    if shortest > len(Xs[i]):
        shortest = len(Xs[i])

# ブロックが消える時間を求める前処理
# ブロックbが消える時刻を時刻vanish[b]とする
vanish = dict()
for i in range(shortest):
    # ある列が消えるのは、各ブロックのうち振ってくるのが一番遅いブロックが降ってきた時点
    latest = -1
    blocks = []
    for j in range(1, W + 1):
        if latest < Xs[j][i][0]:
            latest = Xs[j][i][0]
        blocks.append(Xs[j][i][1])
    for b in blocks:
        vanish[b] = latest

# クエリに答える処理
Q = int(input())

for q in range(Q):
    t, a = list(map(int,input().split()))
    a -= 1
    # もしブロックaが消えて、かつそれが時刻tと同時以前か？
    if a in vanish and vanish[a] <= t:
        print('No')
    else:
        print('Yes')
