ARC138A Larger Score

問題文はこちらから。
数列先頭の何項かを、隣接する2要素をスワップすることを繰り返して最初より大きくする問題。

この問題は、数列の第\(K\)項目までのある項(\(p\)項目とする)と、数列の\(K + 1\)項目以降のある項(\(q\)項目とする)に着目して、\(A_p < A_q\)なる場合に以下のような操作を考えればよい。
・\(p\)項目が最初の\(K\)項から外れるようにスワップ操作を繰り返す
・\(q\)項目が最初の\(K+1\)項目以降から外れるようにスワップ操作を繰り返す
この操作回数は結局\(q - K + K - p = q - p\)回行われるから、後は適切にこれを探索すればよい。
ある\(q\)を固定した時、\(p\)は\(A_p < A_q\)を満たす中で最も後ろの方にあるものを選べばよい。よって先頭\(K\)項を要素の小さい順（同じならインデックスの小さい順）にソートして、条件を満たすギリギリのところまで調べることを繰り返せばよい。
\(q\)が小さい順に貪欲に調べていけば適切に処理できる。
最初のソートがボトルネックになり、時間計算量は\(O(N \log_{}{N})\)程度で済む。実装例は以下の通り。

import collections

N, K = list(map(int,input().split()))
A = list(map(int,input().split()))

initals = [ [A[i], i] for i in range(K)]
initals.sort()
initals = collections.deque(initals)
D = dict()

for i in range(K, N):
    while initals:
        p, q = initals.popleft()
        if p < A[i]:
            D[q] = i
        else:
            initals.appendleft([p, q])
            break

answer = 10 ** 10
for k, v in D.items():
    if answer > v - k:
        answer = v - k
if answer == 10 ** 10:
    print(-1)
else:
    print(answer)
あらゆるときにソートがネックがち。pythonのソートはちょっと調べただけでは何をしてるのかあんまり分からないので、いつか腰を据えて調べてみたい。
C++はヒープソートとクイックソートを組み合わせているらしく、これは何となくピンとくる（クイックソートの再帰の深さが一定を超えたらヒープソートに切り替える、みたいなことだと理解している）。
何をどうソートするかがカギになる問題だった。アルゴリズムはソートに始まると言っている人もいたが、ほんとにその通りだと思う。
