ABC478C Sort Subarray

問題文はこちらから。
数列の一部をソートして全体を昇順にできるかを調べる問題。

イメージとしては、先頭の何項かであって昇順に並べられるのがどこまでかを調べ、後ろの何項かであって昇順に並べられるのがどこまでかを調べ、昇順に並べられない範囲をソートして上手く行くかを調べる。
実装上はこんな感じにする
・数列の1項目からK項目までをSortedListにぶち込む
・K+1項目からN項目までをキュー(back)にぶち込む
・空のスタック(front)を用意する。i=1とする。

・次の4条件すべてを満たしていれば'Yes'を出力して終わり、なければSortedListから\(A_i\)を削除してfrontにぶち込み、backの先頭の項を削除してSortedListにぶち込む。 ①frontの末尾の項（空の場合は0とする) \(\leqq\) SortedListの最小値
②SortedListの最大値 \(\leqq\) backの先頭の項（空の場合は∞とする)
③frontが昇順
④backが昇順

愚直にやっても時間計算量は\(O(K\log_{}{N})\)程度で押さえられ、充分に高速である。以下の実装例ではbackが昇順になるギリギリの範囲から上記操作を始め、かつfrontが昇順にならなくなったらすぐに捜査を打ち切ることでより短縮を試みた。
実装例は以下の通り。

import sortedcontainers
import sys

N, K = list(map(int,input().split()))
A = list(map(int,input().split()))

INF = 10 ** 10
front = [-1]
back = [INF]
start = 0
ok_flag = False

for i in range(N - 1, K - 1, - 1):
    if back[-1] >= A[i]:
        back.append(A[i])
    else:
        start = i - (K - 1)
        break

for i in range(start):
    if front[-1] <= A[i]:
        front.append(A[i])
    else:
        print('No')
        sys.exit()

middle = sortedcontainers.SortedList()
for i in range(start, start + K):
    middle.add(A[i])

while True:
    if front[-1] <= middle[0] and middle[-1] <= back[-1]:
        print('Yes')
        break
    middle.discard(A[start])

    if front[-1] <= A[start]:
        front.append(A[start])
    else:
        print('No')
        break

    q = back.pop()
    if q == INF:
        print('No')
        break
    middle.add(q)
    start += 1
