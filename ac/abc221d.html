ABC221D Online games


問題はこちら。
何人ログインしていた日があるかを出力する問題。

日数に注目して累積和を取ろう、と最初は思ったわけだが、制約上それは厳しい。
\(10^9\)日をシミュレーションすることはできない。
一方で、人の出入り自体は2N回しか起きていないので、こちらを主体に見るのは良さそうだ。
ログインする日とログアウトする日をすべて記録しておくと、それ以外の日にログインしている人の数が増減することはないから、間の日数に何人いたかさえ記録しておけばよい。

具体的には
・ログインしているユーザーの人数humansと、サービス開始からの経過日数dateを記録しておく。また、配列Dを初期化しておく
・あるユーザーがログイン/ログアウトするなら、今の経過日数-dateをD[humans]に加える。
→ログインする場合、humansを1インクリメントする。ログアウトする場合、humansを1デクリメントする。
→dateを今の経過日数で上書きする
というような操作を繰り返せばよい。
実装例は以下の通り。

N = int(input())
Logins = []
for i in range(N):
    a, b = list(map(int,input().split()))
    Logins.append([a, 0])
    Logins.append([a + b, 1])

D = [ 0 for _ in range(N)]

humans = 0
date = 1
Logins.sort()

for i in range(2 * N):
    if humans > 0:
        D[humans - 1] += Logins[i][0] - date
    
    if Logins[i][1] == 0:
        humans += 1
    else:
        humans -= 1
    date = Logins[i][0]

print(*D)
累積和に囚われると辛いが、本質的にはあまり難しいことを要求されない問題。
にしても、\(10^{100}\)日続くソシャゲとはいったい何なのだろう……。
