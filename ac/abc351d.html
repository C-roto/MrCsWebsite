ABC351D Grid and Magnet


問題はこちら。 磁石が置いてあるグリッドにおいて、移動できる場所を探す問題

以下、上下左右のマスに磁石がなく、かつ磁石が置かれていないマスを「磁石の影響下にないマス」とする。「磁石の影響下にないマス」でないマスを「磁石の影響下にあるマス」とする。

最初にとある方法が思いついたのだが、実装の際に色々いじるのがめんどくて一回放棄した。
末尾でまとめているのでそちらをご覧ください。

今回ならBFSが役に立ちそうに思える。こんな感じのアルゴリズムはどうだろう。
①まだ手順②を行っていない「磁石の影響下にないマス」を探す。なければ終了。
②そのマスから遷移可能な「磁石の影響下になく、かつ未探索のマス」もしくは「上下左右に磁石があるマス」の個数を数える（ここがBFS）。探索の過程で通ったマスは探索済みにしておく。
③今数えた値が暫定最大値より大きければ更新し、①に戻る。

正当性について考える。
あるマスから遷移可能なマスは
・磁石の影響下にあるマスにおいては0マスまたは1マス
・磁石の影響下にないマスにおいては、「自ら」もしくは「有限回の遷移で辿り着け、かつ磁石の影響下にないマス」もしくは「有限回の遷移で辿り着け、かつ上下左右に磁石があるマス」の合計数
になる。これを正しく判断するために、②の手順をもう少し細かく書いてみる
。 ・まずQueueを用意して、①で探してきたマスを突っ込む。
・値Counterを用意し、1で初期化しておく。
・Queueに何か入っている限り、Queueをpopして中身を見る。
・取り出したマスの上下左右にあるマスを調べる。
・もしその中に「磁石の影響下になく、かつ今回のBFS中では未探索のマスA」があるなら、マスAを今回のBFS中では探索済みの状態にしてQueueに突っ込み、Counterを+1する。
・もしその中に「上下左右に磁石があり、かつ今回のBFS中では未探索のマスB」があるなら、マスBを今回のBFS中では探索済みの状態に変え、Counterを+1する。
・Queueに何か入っていれば、Queueからpopするところまで戻る。

正当性を示すとしたら、
・あるマスから遷移可能なすべてのマスを、ただ1度だけ数え上げているか？
を調べる必要があり、これは、
・探索済みのマスは、そのBFS中でただ1度だけCounterの値を変化させるのみなので、未探索から探索済みに代わるちょうど1回で期待通りに増加する
・始点から遷移可能なマスは「始点から直接遷移可能」または「始点から遷移可能な磁石の影響下にないマスから遷移可能」のいずれかになっている
・始点から遷移可能なマスは上記ですべて
であることを確かめればよく、これは現に正しい。

時間計算量はどうだろうか？
BFSの時間計算量が増えるのは既に探索済みの頂点を再探索する場合だ。
上記のまま実装すると「磁石の影響下にないマス」すべてで独立にBFSを行うことになってしまい、効率が悪い。
ここで、それまでのBFSで一度でも到達したことのある「磁石の影響下にないマス」を再度調べる必要がないことに注意する。そのようなマスは、あるマスを始点として遷移可能なマスであり、この2マスは相互に行き来可能であるからだ（厳密な証明は省くが、直観的には明らかだろう）。
よって、一度でも到達したことのある「磁石の影響下にないマス」は2度調べないようにする。すると、すべての「磁石の影響下にないマス」はただ1度だけBFSで到達するのみになるから、かなり効率が良くなる。
手順の途中で、以前のBFSで数えた「上下左右に磁石があるマス」を再度カウントすることもありうるが、そこから遷移可能なマスが増えないことから、結局全体の計算量は「磁石の影響下にないマス」の個数の「1マスから可能な遷移先の個数」倍で抑えられるはずだ。
よって、1マスから可能な遷移先の個数を\(K\)個として、時間計算量は\(O(KHW)\)で済み、今回の制約下ならおよそ期待通りの時間で動作するだろう。
実際の実装は以下の通り


import collections

# グリッド探索のお供たち
# m_1,m_2はforで回して上下左右に移動してもらうためのもの
# isinはグリッドの中に納まっているかの判定
m_1 = [0, 1, 0, -1]
m_2 = [1, 0, -1, 0]

def isin(h, w):
    return 0 <= h <= H - 1 and 0 <= w <= W - 1

# 磁石の付近にあるマスか？
def nearmagnet(h, w):
    for i in range(4):
        nh = h + m_1[i]
        nw = w + m_2[i]
        if isin(nh, nw) and S[nh][nw] == "#":
            return True
    return False

# 磁石のおいてあるマスか？
def ismagnet(h, w):
    return S[h][w] == "#"

# 幅優先探索
def bfs(h, w, hmt):
    que = collections.deque([[h, w]])
    Visited[h][w] = hmt
    counter = 1
    while que:
        ph, pw = que.popleft()
        for k in range(4):
            nh, nw = ph + m_1[k], pw + m_2[k]
            if isin(nh, nw):
                if Magnetstate[nh][nw] == 0 and Visited[nh][nw] == 0:
                    que.append([nh, nw])
                    Visited[nh][nw] = hmt
                    counter += 1
                elif Magnetstate[nh][nw] == 1 and Visited[nh][nw] != hmt:
                    Visited[nh][nw] = hmt
                    counter += 1
    return counter

H, W = list(map(int,input().split()))
S = []
for _ in range(H):
    S.append(input())

# 0は磁石に隣接していない、1は磁石のそばにある、2は磁石そのもの
# 以下、磁石に隣接しているか、磁石そのもののマスのことを「磁石の影響下にあるマス」とする
Magnetstate = [ [0 for _ in range(W)] for _ in range(H)]
Visited = [ [ 0 for _ in range(W)] for _ in range(H)]

for i in range(H):
    for j in range(W):
        if nearmagnet(i, j):
            Magnetstate[i][j] = 1
        if ismagnet(i, j):
            Magnetstate[i][j] = 2

# hmt(howmanytimes)は「今が何回目のbfsか?」をカウントしておく変数
# 未探索かつ磁石が付近に無いマスを起点にbfsして行けるマスを数える
# 探索済みかどうかはVisitedが0かどうかで判断する
answer = 1
hmt = 1
for i in range(H):
    for j in range(W):
        # 探索済み、もしくは磁石の影響下にあるマスかを判断
        if Visited[i][j] != 0 or Magnetstate[i][j] > 0:
            continue
        # bfsする(Visitedの幾つかのセルの値が変更されることに注意)
        count = bfs(i, j, hmt)
        hmt += 1
        answer = max(answer, count)

print(answer)
実はBFSじゃない方法でも実装できる。
最初に書いた通り、その方法を以下の折り畳みに書いてみる。
最初に思いついた方針 最初に思いついたのは、相互に行き来できる白マス同士を「1つのグループ」と見なして、そのグループのマス数と、グループが触れている「上下左右に磁石があるマス」を数えるという方法だ。
「グループにする」という発想は、素集合データ構造におけるUnion-Find操作で実現できる。
もはやデータ構造の名前自体がUnion-FindとかUnion-Find木とか呼ばれているが、『アルゴリズムイントロダクション　第4版』には「互いに素な集合族のためのデータ構造」という名称で載っており、ややこしい。
この操作は、「要素同士をグループ化して、そのグループのリーダー(代表元)に色んな情報を持たせて楽をする」というようなもので、複雑な分応用が利く素敵なデータ構造だ。
これを使うと
・磁石の影響下にないマスをUnion操作でグループ化する。グループ化後の同グループに属するマスの個数を、リーダーのマスに記録しておく。
・各黒マスの周りにあるグループに行けるマス数を+1していく（グループの大きさに+1すれば良い）
・各グループの大きさの最大値を全走査して調べる。
という感じで調べられる。実装例は以下の通り。

class DisjointSetUnionfind:
    def __init__(self, N: int):
        self.number = N
        self.parent = [ -1 for _ in range(N)]
        self.size = [ 1 for _ in range(N)]

    def find(self, v : int):
        compress = []
        while self.parent[v] != -1:
            compress.append(v)
            v = self.parent[v]
        for c in compress:
            self.parent[c] = v
        return v

    def union(self, u: int, v: int):
        ru = self.find(u)
        rv = self.find(v)
        if ru != rv:
            if self.size[ru] < self.size[rv]:
                ru, rv = rv, ru
            self.parent[rv] = ru
            self.size[ru] += self.size[rv]

m_1 = [0, 1, 0, -1]
m_2 = [1, 0, -1, 0]

def isin(h, w):
    return 0 <= h <= H - 1 and 0 <= w <= W - 1

def nearmagnet(h, w):
    for i in range(4):
        nh = h + m_1[i]
        nw = w + m_2[i]
        if isin(nh, nw) and S[nh][nw] == "#":
            return True
    return False

def ismagnet(h, w):
    return S[h][w] == "#"

H, W = list(map(int,input().split()))
S = []
for _ in range(H):
    S.append(input())

# 0は磁石に隣接していない、1は磁石のそばにある、2は磁石そのもの
Magnetstate = [ [0 for _ in range(W)] for _ in range(H)]
# S[i][j]はuf.container[i * W + j]と対応するものとして考える
uf = DisjointSetUnionfind(H * W)

for i in range(H):
    for j in range(W):
        if nearmagnet(i, j):
            Magnetstate[i][j] = 1
        if ismagnet(i, j):
            Magnetstate[i][j] = 2

for i in range(H):
    for j in range(W):
        if Magnetstate[i][j] > 0:
            continue
        for k in range(2):
            ni = i + m_1[k]
            nj = j + m_2[k]
            if isin(ni, nj) and Magnetstate[ni][nj] == 0:
                    uf.union(i * W + j, ni * W + nj)

for i in range(H):
    for j in range(W):
        if Magnetstate[i][j] != 1:
            continue
        tmp = set()
        for k in range(4):
            ni = i + m_1[k]
            nj = j + m_2[k]
            if isin(ni, nj) and Magnetstate[ni][nj] == 0:
                group = uf.find(W * ni + nj)
                if group not in tmp:
                    uf.size[group] += 1
                    tmp.add(group)
                
answer = 1
for i in range(H):
    for j in range(W):
        if answer < uf.size[i * W + j]:
            answer = uf.size[i * W + j]

print(answer)
