ABC156D Bouquet

問題文はこちらから。
特定の個数を避け、たくさんの花から選んで花束を作る問題。

縛りがない場合は\(n\)本すべての花について「花束に使う/使わない」の2通りずつがあり、かつすべてを選ばない場合を除けばいいので、花束は\(2^n-1\)種類できる。
そのうち\(a\)本からなる花束は、\(n\)本から\(a\)本を選ぶ方法の数である\(\binom{n}{a}\)種類が存在する。\(b\)本からなる花束も同様に\(\binom{n}{b}\)種類ある。
よって求める種類数は\(2^n-1 - \binom{n}{a} - \binom{n}{b}\)となる。

なのでまあこれを求めればおしまいだから、考察パートに大変なところはない。
ただし、実装面で\(n\)が結構大きくなりうるところに気を付ける必要がある。
単純に\(n!\)を求めて、\((n-a)!\)と\(a!\)の逆数をそれぞれ求めて、とやっているとTLEしてしまう。
一方で、\(\binom{n}{a}\)の分子は\(n\)から\(n-a+1\)までのA個の数の積であるし、分母は\(1\)から\(a\)までの\(a\)個の数の積であるから、分子を掛けて分母を掛けて……と愚直にやっていけば時間計算量は\(O(a)\)程度にまで落とせる。
今回\(mod 10^9+7\)で求めたい二項係数は2つしかないから、前計算も実際の値を求める計算も\(O(a)\)程度で終わる。ネックになるのはここか、\(2^n\)の\(mod 10^9+7\)を求めるためのダブリングのいずれかで、すると全体の時間計算量は\(O(a+b+log_{}{n})\)程度で見積もることができる。これは制約下では充分に高速と言えるだろう。
実装例は以下の通り。

mod = 1000000007

def doubling(x, p, m):
    res = 1
    d = x
    while p > 0:
        if p & 1 == 1:
            res *= d
            res %= m
        d = d ** 2
        d %= m
        p = p >> 1
    return res

def frac_mod(N, A):
    res = 1
    t = 1
    for i in range(N, N - A, -1):
        res *= i
        res %= mod
        res *= invs[t]
        res %= mod
        t += 1
    return res

N, A, B = list(map(int,input().split()))
frac = [0, 1]
invs = [0, 1]
for i in range(2, max(A, B) + 1):
    frac.append((frac[-1] * i) % mod)
    invs.append(doubling(i, mod - 2, mod))

H = doubling(2, mod, N) - 1
A = frac_mod(N, A)
B = frac_mod(N, B)

H -= A
if H < 0:
    H += mod
H -= B
if H < 0:
    H += mod
print(H)
まあ別に大したことがある問題かと言われると、そんなことはない。
一方で階乗とmodをちゃんと考えないといけないなという戒めになった。
