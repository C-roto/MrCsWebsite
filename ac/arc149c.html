ARC149C Avoid Prime Sum

問題文はこちらから。
隣り合う2数の和が素数にならないように数字を埋めていく問題。

今回突破口になったのは「\(N\)のときに具体的な構成があると仮定すると、それをうまく利用して\(N+1\)のときの構成を作れるのでは？」という発想だ。つまり数学的帰納法のような発想と言える。
制約下で必ず得られることの保証がされていることからも、（総当たりして見つけた可能性はあるが、）何か頭の良い構成方法がある可能性もある。

\(N\)での構成を考えるために、条件を緩めてみる。
「隣り合う2数の和が素数でない」という条件はかなり強力だが、考えにくくもある。ここで、もう少し条件を緩和して「隣り合う2数の和が偶数になる」という条件を考えてみる（2数の和は3以上になるので、2になる可能性は考慮しなくて良い）。
こうなると、なるべく偶数同士や奇数同士をまとめて置いておきたい（奇数と偶数が接する場所をなるだけ減らしたい）と考えたくなるのが人情だろう。
つまり\(N\)のときに、なるべく偶数同士や奇数同士が固まっているような構成を仮定して、\(N+1\)のときもそれに則って構成することを考える。

結論、偶奇と3の倍数がこの問題を解くカギだ。
左からi行目上からj列目のマスを\((i,j)\)と書くことにすると、以下の5条件をすべて満たすような\(N \times N\)マスの数字の配置が必ず存在する。
・マス\((N,N)\)には3で割って1余る数が入っている
・マス\((N-1,N)\)とマス\((N,N-1)\)には3で割って2余る数が入っている
・\(N\)が偶数ならば、マス\((1,N),(2,N),...(N,N)\)に偶数が入っており、\((N,1),(N,2),...(N,N-1)\)に奇数が入っている
・\(N\)が奇数ならば、\((1,N),(2,N),...(N-1,N)\)に偶数が入っており、\((N,1),(N,2),...(N,N)\)に奇数が入っている状態にする
・問題文の条件を満たす。つまり、上下左右に隣接する任意の2つの数の和は素数でなく、1から\(N^2\)までのすべての正の整数が1度ずつマスに書かれている。
証明は数学的帰納法で行える。
\(N=3\)の場合、以下の配置が5条件すべてを満たす。

8 1 9
7 3 5
2 6 4
\(N\)の場合に5条件を満たす配置ができていたと仮定し、\(N+1\)の場合を考える。\(N\)が奇数の場合の証明をすれば、偶数の場合もほとんど同様にして完了するので、奇数の場合のみ詳述する。

●\(N\)が奇数の場合
\((N+1) \times (N+1)\)マスのうち、左上の方の\(N \times N\)マスに、\(N \times N\)マスの条件を満たす配置を丸ごとそのまま埋める。
今盤面にない偶数は\(N^2+1, N^2+3, ..., N^2 + 2N + 1\)の\(N + 1\)個あり、これは公差2で数列の長さが3以上の等差数列をなす。公差2、長さ3以上の等差数列の中には、3で割って1余る数と3で割って2余る数が必ず1つずつ以上存在する。
\(N^2+1, N^2+3, ..., N^2 + 2N + 1\)の中にある3で割って1余る数を適当に1つ選び、\(p\)とする。同じくその中にある3で割って2余る数を適当に1つ選び\(q\)とする。
マス\((N+1,N+1)\)に\(p\)を埋め、マス\((N,N+1)\)に\(q\)を埋め、マス\((1,N+1),(2,N+1),...,(N-1,N)\)には残りの偶数を適当に埋める。

同様に、今盤面にない奇数は\(N^2+2, N^2+4, ..., N^2 + 2N\)の\(N\)個あり、これは公差2で数列の長さが3以上の等差数列をなす。公差2、長さ3以上の等差数列の中には、3で割って2余る数が必ず1つずつ以上存在する。
\(N^2+2, N^2+4, ..., N^2 + 2N\)の中にある3で割って2余る数を適当に1つ選び、\(r\)とする。
マス\((N+1,N)\)に\(r\)を埋め、マス\((N+1,1),(N+1,2),...,(N+1,N-1)\)には残りの奇数を適当に埋める。
これにより5条件のうち4条件が満たされていることは明らかである。

最後の条件を満たしていることを示す。
\(1\)から\((N+1)^2\)までの整数が1度ずつ書かれていることは明らかだろう。
つまり隣り合う2数が素数でないことを示せば十分だ。
まず、\(1 \leqq i \leqq N\)かつ\(1 \leqq j \leqq N-1\)なる整数\(i,j\)において、\((i,j)\)と\((i,j+1)\)の和が素数でないこと、および、\(1 \leqq i \leqq N-1\)かつ\(1 \leqq j \leqq N\)なる整数\(i,j\)において、\((i,j)\)と\((i+1,j)\)の和が素数でないことは帰納法の仮定により保証されている。
ここから1か所ずつ検証していく。
・\(1 \leqq i \leqq N\)なる整数\(i\)について、マス\((i,N)\)とマス\((i,N+1)\)の和は（このマスに書かれた数がともに偶数であることから）、明らかに素数ではない。
・\(1 \leqq i \leqq N-1\)なる整数\(i\)について、マス\((N,i)\)とマス\((N+1,i)\)の和は（このマスに書かれた数がともに奇数であることから）、明らかに素数ではない。
・マス\((N,N)\)とマス\((N+1,N)\)に書かれた数は、帰納法の仮定と先の手順から3で割って2余る数と1余る数なので、この2数の和は3で割り切れる。2数の和は明らかに3より大きいから、これは素数ではない。
・残ったマス\((N+1,N)\)とマス\((N+1,N+1)\)、およびマス\((N,N+1)\)とマス\((N+1,N+1)\)の和についても、先と同様に3で割り切れる3より大きい数になるので、素数ではない。
以上、どの隣り合う2数も、その和は素数にならないことが示された。

●\(N\)が偶数の場合
概ね奇数の場合と同様に示すことができる。偶数と奇数の個数が逆転する部分に注意しながら、条件を満たすように端の方を埋めていけばよい。

というわけで、後は上記で盤面の「下」や「右」を構成した方法を繰り返し実行し続ければ、帰納的に条件を満たすマスの埋め方が拡張できる。
出来上がった盤面を見ると、左下の方に偶数、右上の方に奇数が寄るようにできていて、最初に何となく偶数と奇数を固めておきたいと言った通りになった。
盤面に数を埋めていく部分がネックとなり、時間計算量は\(O(N^2)\)程度で済むだろう。実装例は以下の通り。

N = int(input())

# NxNの配置のうち、右下が3で割って1余る数、右下の一つ上と一つ左が3で割って2余る数であるようなものが1つ存在する
# 819,735,264が条件を満たす3x3の配置
# これに条件を満たすようにして値をくっつけていく
A =[[8,1,9],[7,3,5],[2,6,4]]
for i in range(N - 3):
    under = [ -1 for _ in range(i + 4)]
    odds = 0
    even = 0
    odd_check = True
    for j in range((i + 3) ** 2 + 1, (i + 4) ** 2 + 1):
        if i % 2 == 0:
            if j % 2 == 0:
                if j % 3 == 1 and under[-1] == -1:
                    under[-1] = j
                elif j % 3 == 2 and under[-2] == -1:
                    under[-2] = j
                else:
                    under[even] = j
                    even += 1
            else:
                if j % 3 == 2 and odd_check:
                    odd_check = False
                    A[-1].append(j)
                else:
                    A[odds].append(j)
                    odds += 1
        else:
            if j % 2 == 0:
                if j % 3 == 2 and under[-2] == -1:
                    under[-2] = j
                else:
                    under[even] = j
                    even += 1
            else:
                if j % 3 == 2 and odd_check:
                    odd_check = False
                    A[-1].append(j)
                elif j % 3 == 1 and under[-1] == -1:
                    under[-1] = j
                else:
                    A[odds].append(j)
                    odds += 1
    A.append(under)

for i in range(N):
    print(*A[i])
実際に解く際は、
・偶数と奇数を固めたいな～
・小さい場合を具体的に見つけたいな～
を行ったり来たりしながら、つじつまが合わないところだけ3の倍数で誤魔化そう、みたいな感じで思いついていった。

書いた後で公式解説を読んだ。
書いた方法は公式解説の方法と概ね同じだが、公式解説の方が各場合に対してスムーズに生成できるのは利点だろう。一方でアプリオリに与えるべきなのが\(N=3\)の場合のみでよいのは自分の方法の利点かもしれない。
たまたま最初に見つけた\(N=3\)のときの解が、帰納法のベースケースとして使えるもの（実際にはそれを回転した形）だったのが幸運だったと言える。
