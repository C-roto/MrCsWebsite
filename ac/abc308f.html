ABC308F Vouchers

問題文はこちらから。
ディスカウントチケットをどれに使うか考える問題。

クーポンの使い方は色々あるが、結局のところ、使えたはずのクーポンが使えなくなるのが勿体ない。
つまり、各クーポンチケットが対象とする定価順→値引額順に昇順ソートして、商品も定価順に昇順ソートして、今先頭にあるクーポンが今先頭にある商品に使えるか見ればよい。
そして、使えるクーポンの中で最も値引き額が大きいものを選んで商品に使えばよい。使ったクーポンと買った商品をリストから除外して、同じことを繰り返していく。
こうすると、いつでも使える中で最大の割引額を選んでいることになる。使える時に最大割引額を使わない理由もない（いわゆる「交換しても悪化しない」論法）から、この方向で問題なさそうだ。
商品を値段昇順に並べることで、使えるクーポンの集合はクーポンの使用以外で減らなくなる。よって、今使えるクーポンの集合を優先度付きキューなどで管理すれば、時間計算量的にも優しい。
ソートと各回における優先度付きキューに対する処理がネックになって、時間計算量はおよそ\(O\((N + M)(\log_{}{N}+\log_{}{M}))\)程度で抑えられ、これは制約下では充分高速である。
実装例は以下の通り。

import heapq

N, M = list(map(int,input().split()))
P = list(map(int,input().split()))
L = list(map(int,input().split()))
D = list(map(int,input().split()))

Tickets = []
for i in range(M):
    Tickets.append([L[i], D[i]])

Tickets.sort(reverse=True)
P.sort(reverse=True)
HQ = []
heapq.heapify(HQ)

answer = 0
while P:
    p = P.pop()
    while Tickets:
        if Tickets[-1][0] <= p:
            lo, d = Tickets.pop()
            heapq.heappush(HQ, -1 * d)
        else:
            break

    if HQ:
        d = heapq.heappop(HQ)
        answer += p + d
    else:
        answer += p

print(answer)
単純な解法こそ最も気が付きにくいことがあるが、これはそんなことない問題かもしれない。
