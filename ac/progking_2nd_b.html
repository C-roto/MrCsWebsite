第二回全国統一プログラミング王決定戦予選 B Counting of Trees

問題文はこちらから。
頂点間の距離から作れるグラフの個数をあてる問題。

グラフを1つも作れない場合のカウントがちょっと面倒。
「距離0の頂点が1つじゃない」、「頂点の距離が飛び飛び(距離iの頂点があり、かつ距離i+1の頂点がなく、かつ\(i < j\)を満たす距離jの頂点が存在する)」がまずいことはわかるが、うっかり「頂点1が頂点1から距離0ではない」場合を見落としてWAした。
ともあれ、この3条件の1つでも満たされている場合は、グラフは1つもできないので答えは0になる。

これら3条件が満たされていない場合はたやすい。
距離iの頂点が\(C_i\)個あるとする。
このとき、距離i+1の頂点は、距離iの頂点のいずれかとつながっている必要があり、また、どの距離iの頂点とつないでも木であるという条件を保つことはできる。
よって、距離i+1の頂点について、可能な辺のつなぎ方は\({C_i}^{C_{i+1}}\)通りだけある。これをすべての\(i\)に関して出して総積をとればよい。
あまり工夫しなくても、毎回modをとるだけで大した計算量にはならない。
最悪ケースでも時間計算量は\(O(N)\)で抑えられ、このケースにおいては問題ない。
実装例は以下の通り。

N = int(input())
D = list(map(int,input().split()))
mod = 998244353

Vernum = dict()
nums = list()
for i in range(N):
    if D[i] not in Vernum:
        Vernum[D[i]] = 1
        nums.append(D[i])
    else:
        Vernum[D[i]] += 1

nums.sort()
ok_flag = True
# 気ができない条件を1つずつはじく
# 距離0の頂点が1つもないか、あるいは複数ある場合
if 0 not in Vernum or Vernum[0] != 1:
    ok_flag = False
# 頂点1から頂点1の距離が0でない場合
if D[0] != 0:
    ok_flag = False
# 距離iの頂点があるのに距離i+1の頂点がなく、かつi < jなる距離jの頂点がある場合
for i in range(len(nums)):
    if nums[i] != i:
        ok_flag = False

if ok_flag:
    answer = 1
    for i in range(len(nums) - 1):
        tmp = 1
        for j in range(Vernum[i + 1]):
            tmp *= Vernum[i]
            tmp %= mod
        tmp %= mod
        answer *= tmp
        answer %= mod
    print(answer % mod)
else:
    print(0)
