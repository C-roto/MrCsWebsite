ABC469C Cantrip

問題文はこちらから。
あたりが出たらもう1袋、を繰り返して何袋食えるか考える問題。

今の袋を取った時点で、まだ食べることができる袋の最大個数を\(A\)個としておく。
もし、次に取る袋が”o”なら、次の袋を取った時点で次に取れる袋の個数は\(A\)個のまま。
次に取る袋が”x”なら、次の袋を取った時点で次に取れる袋の個数は\(A-1\)個だ。
よって、食べられる袋の最大個数は、「最初に貰う袋のうち”o”の個数」と「途中で拾う”x”の個数」が等しくなる地点における袋の個数と等しい（そのような場所がなければ、すべての袋を食べることができる）。
これは”o”の個数と”x”の個数に関する累積和をとっておいて調べれば、二分探索によって調べきることができる。この部分がネックになって、全体の時間計算量は\(O(N\log_{}{N}\)となり、今回の制約下では十分に高速である。
実装例は以下の通り。

import bisect

N = int(input())
S = input()

o_sum = [ 0 for _ in range(N)]
x_sum = [ 0 for _ in range(N)]
if S[0] == "o":
    o_sum[0] = 1
else:
    x_sum[0] = 1

# 「先頭からk個までにあるoの個数」が「k+1個目からa個までにあるxの個数」を上回らなければOK
# そのようなaであって最大のものを調べる
for i in range(1, N):
    if S[i] == "o":
        o_sum[i] = o_sum[i - 1] + 1
        x_sum[i] = x_sum[i - 1]
    else:
        o_sum[i] = o_sum[i - 1]
        x_sum[i] = x_sum[i - 1] + 1

o_sum.insert(0, 0)
x_sum.insert(0, 0)

for k in range(1, N + 1):
    o_check = o_sum[k]
    p = bisect.bisect_left(x_sum, o_check + x_sum[k])
    if p >= N:
        p = N
    print(p)
こういうの地味に苦手で、「えーと、何と何が等しくて、だから何を調べたらいいんだっけ？」となりがち。
