問題文はこちらから。
リンゴ取りゲームをする問題。

頑張って不変量を探しましょう、或いはGrundy数とか考えましょう、みたいな問題。
Grundy数を考える時のポイントとして、「負け盤面（その状態で手番が回ってきたら負けになる盤面）の特徴量」を考えることがある。要は、
・「負け盤面と同じ特徴を持つ盤面」からは、どういう手を打っても「負け盤面と違う特徴を持つ盤面」に遷移するか、或いはどこにも遷移できない
・「負け盤面と違う特徴を持つ盤面」からは、うまい手を打てば「負け盤面と同じ特徴を持つ盤面」に遷移できる
という条件を満たすような特徴量を探せばよい。今回で言えば負け盤面とは、すべての色のリンゴが0個の状態を指す（正確には最後のリンゴを食べたら勝ちだが、「リンゴが取れなくなったら負け」と考えても意味は変わらず、そして考えやすくなる）。
加えて、1回の操作で1ずつ変化をさせると、偶奇性に着目したい気持ちになる。
以上を踏まえて考えると、今回の特徴量は「各色のリンゴの個数がすべて偶数かどうか」になる。これはもちろん、「すべての色のリンゴが0個の状態」を表す特徴である。
そして、上記の条件が満たされていることは以下のように調べられる。
・各色のリンゴの個数がすべて偶数であるときは、同色を1個ずつしか取れず、パスができない都合上、必ず1つ以上の色のリンゴが奇数になる。全部0個なら負けで、遷移できない。
・各色のリンゴの個数に奇数のものがあるとき、奇数個ある色のリンゴを1つずつ食べれば、すべてが偶数個の状態で相手に手番を回すことができる。
というわけで、勝利条件は
・すべての色のリンゴが偶数個である場合、ルンルン（後手）が勝つ。
・そうでない場合、あなた（先手）が勝つ。
という、至極単純な条件分岐にまとまる。各色のリンゴに対して個数を全て数える部分がネックとなり、時間計算量は\(O(N)\)。この制約下では充分高速である。
実装例は以下の通り。

N = int(input())

answer = "second"
for i in range(N):
    a = int(input())
    if a % 2 == 1:
        answer = "first"
print(answer)
考察が9割9分で、後は眠くても書けるようなコードを書くだけ。
Grundy数はGrundy数の概念そのものも面白いんだが、その背景にある証明手法は汎用性があって面白い。
