ABC223D Restricted Permutation


問題文はこちら。

「ある数字がある数字の前に来る」という条件を満たすようにして数列を並び替える問題。
「辞書順最小」という制約があるが、これが少し面白い。

こういう「要素同士の順番」が規定されている問題は、実はグラフの問題に帰着できることが多い。
今回ならば「トポロジカルソート」という考え方を使うことで解くことができる。
詳細はまた別にまとめるなどするつもりだが、「前にある要素に向かって後ろの要素から有向辺を出す」として作った有向グラフが非巡回グラフであるかを調べればよい。

さて、今回の問題の面白いところはkahnのアルゴリズム(トポロジカルソートの肝になるアルゴリズム)を回すときに頂点を管理しているデータ構造にある。
特に目的がなく、トポロジカル順を何か1つでも出せばよいのならstackやqueueを使って実装することが多いのだが、今回は「辞書順で最小のもの」を出力するよう要求されている。
つまり、できる限り頂点番号が小さい順に判定するよう調整をする必要がある。
kahnのアルゴリズムで頂点を取り出す操作を行う際に、同時に頂点管理用のデータ構造に入っている頂点たちは、どれを取り出してもトポロジカル順になるはずである。
ということは、なるべく小さいものを取り出すという目的に適うのはヒープだ。というわけで、stackやqueueの代わりにヒープを使うと望みの通り辞書順最小のものが出力される。

自分の実装は以下の通り。

import heapq

# グラフ構築
N, M  = list(map(int,input().split()))
G = [ list() for _ in range(N)]
for i in range(M):
    a, b = list(map(int,input().split()))
    a -= 1
    b -= 1
    G[a].append(b)

# トポロジカルソートのための入次数サーチ
indeg = [ 0 for _ in range(N)]
for u in range(N):
    for v in G[u]:
        indeg[v] += 1

# 頂点管理
HQ = []
heapq.heapify(HQ)
for i in range(N):
    if indeg[i] == 0:
        heapq.heappush(HQ, i)

# kahnのアルゴリズムで回す
Result = []
while HQ:
    p = heapq.heappop(HQ)
    Result.append(p + 1)
    for q in G[p]:
        indeg[q] -= 1
        if indeg[q] == 0:
            heapq.heappush(HQ, q)

# 巡回グラフだったら-1を出す
if len(Result) < N:
    print(-1)
else:
    print(*Result)
トポロジカルソート用の自己ライブラリを用意しておくと、ある程度はそれを貼るだけで対応できる。
トポロジカルソートそれ自体も面白い概念なので、いつか自分用メモとしてしっかりまとめておきたい。
