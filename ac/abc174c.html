ABC174C Repsept

問題文はこちらから。
7だけでできた数が割れる条件を探す問題。

今回扱うような、十進法表記で7が\(n\)個並んだ数を\(a_n\)と書き、\(n\)番目のレプセブン数と呼ぶことにする。
まず、明らかに\(K\)が2や5の倍数の場合、いかなるレプセブン数も\(K\)で割り切れない（下1桁が偶数や5になることがないから）。
以下、\(K\)は2でも5でも割り切れない正の整数だとする。
結論から言えば、このとき、1以上\(9K\)以下の正の整数\(m\)が存在して、\(a_m\)は\(K\)で割り切れる。
証明はオイラーの定理を認めれば容易い。\(K\)と互いに素な1以上\(K-1\)以下の整数の個数を\(f(K)\)と書くとすると、オイラーの定理から\(10^{f(k)} \equiv 1\)となることがわかる。
\(a_n = 7 \cdot \frac{10^n-1}{9}\)であるから、\(K\)が3の倍数でないとき、\(a_{f(K)}\)は明らかに\(K\)で割り切れる。
\(K\)が3の倍数の時でも、\(9f(K) < 9K\)であるから、\(\frac{10^{9f(K)}-1}{9}\)は\(9K\)で割り切れて、特に\(a_{9f(k)}\)は\(K\)で割り切れる。
したがって、高々\(9K\)個の数を調べれば、条件を満たす最小の\(n\)を見つけることが確実に可能である。今回の制約上、それは難しくない。
単純に最大9K回のループを回して、漸化式\(a_1=7,a_{n+1}=10a_n+7(n=1,2,..)\)を繰り返し使用して各\(n\)に関する余りを求めればよい。
ループ内の各計算は定数時間とみなせ、全体の時間計算量は\(O(K)\)で抑えることが可能である。
実装例は以下の通り。

import sys

K = int(input())

if K % 2 == 0 or K % 5 == 0:
    print(-1)
    sys.exit()

counter = 1
a = 7
for _ in range(9 * K):
    if a % K == 0:
        break
    a *= 10
    a += 7
    a %= K
    counter += 1
print(counter)
最大値を保証することで解法を正当化する問題は好き。
でも何かわからないのに通ったというもやもやが残ることもあり、それは好きじゃないのかも。
