ABC245D Polynomial division

問題文はこちらから。 整式と、それを整数係数の範囲内で因数分解した1つが与えられるので、もう片方を特定する問題。

高校数学だなあ。
具体的には\(B_k\)について、\(\sum_{i=0}^{min(N, M - k)} A_{N - i}B_{k + i} = C_{N + k}\)が成り立つ。
（次数の和が\(M+k\)になる組を掛けて総和を取る）
ということは、\(\displaystyle B_k = \frac{C_{N + k} - \sum_{i=1}^{min(N, M - k)} A_{N - i}B_{k + i}}{A_N}\)が成り立つ。
右辺分子を求めることは、適当に見積もっても時間計算量\(O(N+M)\)で出来るわけなので、この操作全体は最低でも時間計算量\(O(M(N + M))\)程度で完遂でき、これは十分高速である（真の上界として妥当かは検討の余地あり）。
よって上記の計算を愚直にやるプログラムを書けばよい。実装例は以下の通り。

N, M = list(map(int,input().split()))
A = list(map(int,input().split()))
C = list(map(int,input().split()))

B = [ 1000 for _ in range(M + 1)]
for i in range(M + 1):
    tmp = 0
    for j in range(i):
        if N >= N - i + j >= 0 and M >= M - j >= 0 and B[M - j] != 1000:
            tmp += A[N - i + j] * B[M - j]
    B[M - i] = (C[N + M - i] - tmp) // A[N]

print(*B)
と、書いた後に知ったが、Pythonにはnumpyという有名なライブラリがあり、それには多項式の割り算を行える機能があるそうだ（実際に書いて通したが、あまりきれいなコードではないので割愛。公式解説のユーザー解説の中により良い実装があるので、そちらを読むべし）。
今回の目的なら上記の内容で全く問題ないし、こちらの方が早いのだが、色々知っておいて損はないだろう。
