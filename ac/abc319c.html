ABC319C False Hope

問題文はこちらから。
高橋くんに偽りの希望を持たせ続けながらビンゴさせる問題。

方針としてはあり得る埋め方の順を全列挙し、その順に埋めたら高橋くんの希望が打ち砕かれるかどうかを順次調べるという方向でいく。
問題の制約から、高橋くんががっかりすることと、あるタイミングで「2マス同じ数字があることが分かっていて、かつ残り1マスが未開封」であるようなラインが存在することは同値である。よって、新しくマスを開けるたびにすべてのラインを走査して先の条件を満たすか調べ、満たしているならNGとする、という方法が妥当になる。
後は全体のうちいくつがNGだったか調べ、NGじゃなかった個数を全体の個数で割って割合を出せばよい。

ところで、愚直にマスを埋めるシミュレーションを行うとPyPyではギリギリ実行時間制限に間に合わない。
そこで、「同じライン中にある同じ数字のマスの組」を全列挙し、同じライン中の違う数字のマスと合わせて保持しておく。
例えば\(c_{1,1} = c_{1,3}\)だった場合、\([(1, 1), (1, 3), (1, 2)]\)という組を保持しておく。
そして、各マスを埋める順番を全列挙し、保持している各3つ組に対し、前の2つが先に出て、最後の1つがその2つが出た後に出ていた場合はNGのカウントを1つ増やせばよい。
これなら毎回実際に盤面を構築する必要はなく、単に長さ9の配列の全体を最大8回(実装上は2倍の16回だが、これくらいなら気にすることはない)舐めればよいだけになる。
これならPyPyでも余裕で回る。実装例は以下の通り。

import itertools

# 順列中に指定した並びが登場するかチェック
def isin_sqeuence(seq, ngs):
    first_flag = False
    same_flag = False
    for e in seq:
        if same_flag and e == ngs[2]:
            return True
        elif first_flag and e == ngs[1]:
            same_flag = True
        elif e == ngs[0]:
            first_flag = True
    return False

C = []
for i in range(3):
    c = list(map(int,input().split()))
    C.extend(c)

S = itertools.permutations([i for i in range(9)], 9)
# 縦横斜めに並んでいるインデックスを全列挙
D = [[0, 3, 6], [1, 4, 7], [2, 5, 8], [0, 1, 2], [3, 4, 5], [6, 7, 8], [0, 4, 8], [2, 4, 6]]
NGs = []
for d in D:
    if C[d[0]] == C[d[1]]:
        NGs.append([d[0], d[1], d[2]])
        NGs.append([d[1], d[0], d[2]])
    elif C[d[1]] == C[d[2]]:
        NGs.append([d[1], d[2], d[0]])
        NGs.append([d[2], d[1], d[0]])
    elif C[d[0]] == C[d[2]]:
        NGs.append([d[0], d[2], d[1]])
        NGs.append([d[2], d[0], d[1]])

ng_counter = 0
full_counter = 362880
for s in S:
    for n in NGs:
        if isin_sqeuence(s, n):
            ng_counter += 1
            break

print((full_counter - ng_counter) / full_counter)
