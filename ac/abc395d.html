ABC395D Pigeon Swap


問題文はこちら。

何をしたいか整理しないととても混乱する問題。
愚直に言われた通りのことをやろうとすると何が起こるか考える。
集合を要素に持つ配列BOXを用意し、巣箱\(i\)に鳩\(j\)がいることをBOX[i]の要素にjがあることで表現しよう。
すると、クエリ1は時間計算量\(O(1)\)で実行できるが、クエリ2は鳩の数によって時間計算量は左右されるし、クエリ3も前から走査する形式をとると時間がかかりそうだ。

考えられる工夫として「どの鳩がどの巣箱にいるか」も同時に管理するというものがある。
これによってクエリ3も定数時間で実行できるようになる。
しかし、依然としてクエリ2がしんどい。どうしようか。
箱の中の鳩を直接入れ替えるから大変なのであって、鳩を入れ替えずに「箱の中身を入れ替えた状態」を作れれば良いのだ。
例えば、箱にラベルを貼っておき、そのラベルを入れ替えればこれは実現できる。

まとめると、これらのことを適切に実装するには……
・「鳩の番号」と「箱の位置」を管理する配列Pegion(Pegion[i] = jのとき、鳩\(i\)が箱\(j\)にいることを指す)
・「箱のラベル」と「箱の位置」を管理する配列Labels(Labels[i] = jのとき、前から\(i\)番目の箱にラベル\(j\)が貼られていることを指す)
・「箱の位置」と「箱のラベル」を管理する配列Oreders(Oreders[i] = jのとき、ラベル\(i\)が貼られた箱が前から\(j\)番目にあることを指す)
このようにすれば、
・クエリ1はPegions[a]をOreders[b]に更新することで、「鳩aの位置を前からOreders[b]番目の箱」に変更することができる。
同様にクエリ2や3も処理できる。実装は以下の通り。

N, Q = list(map(int,input().split()))
# 何番目の箱に何番の鳩がいるか
Pegions = [ i for i in range(N + 1)]
# 何番目の箱が何のラベルか
Labels = [ i for i in range(N + 1)]
# 何のラベルの箱が何番目にあるか
Oreders = [ i for i in range(N + 1)]

for q in range(Q):
    query = list(map(int,input().split()))
    if query[0] == 1:
        a, b = query[1], query[2]
        Pegions[a] = Oreders[b]
    elif query[0] == 2:
        a, b = query[1], query[2]
        x = Oreders[a]
        y = Oreders[b]
        Labels[x] = b
        Labels[y] = a
        Oreders[a] = y
        Oreders[b] = x
    else:
        a = query[1]
        print(Labels[Pegions[a]])
