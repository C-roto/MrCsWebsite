Diverta 2019 Programming Contest C AB Substrings

問題文はこちらから。
文字列を上手く連結して特定の文字の並びをいっぱい作る問題。

まず、文字列中に"AB'が直接含まれていれば、どう連結しても必ずその並びは保たれるので、この数をカウントしておく（以下これを「'AB'の個数」と呼ぶ）。
また、'B'が先頭にある文字列と'A'が末尾にある文字列は、繋げ方次第で'AB'を作ることができる。
「'B'が先頭にあるが、'A'が末尾にない文字列」と「'B'が先頭になく、'A'が末尾にある文字列」と「'B'が先頭にあり、'A'が末尾にある文字列」という3つのパターンがあるので、これらを別々に数える。
以下ではこれらの個数をそれぞれ「先頭が'B'の個数」、「末尾が'A'の個数」、「先頭が'B'で末尾が'A'の個数」と称する。

まず、「先頭が'B'の個数」と「末尾が'A'の個数」が一致する場合は、これらを順に組み合わせることで「先頭が'B'の個数」個の'AB'を得ることができる。
あとは「'B'が先頭にあり、'A'が末尾にある文字列」を順に組み合わせることで、「先頭が'B'で末尾が'A'の個数」-1個の'AB'を得ることができる（「'B'が先頭にあり、'A'が末尾にある文字列」がない場合は0個）。

「先頭が'B'の個数」と「末尾が'A'の個数」が一致しない場合は、この2つのうち少ない方の個数の'AB'を連結によって得ることができる。
余ったそれと「'B'が先頭にあり、'A'が末尾にある文字列」を上手く組み合わせて、「先頭が'B'で末尾が'A'の個数」個の'AB'を得ることができる。

よって、答えは以下の通り。
・「先頭が'B'の個数」と「末尾が'A'の個数」が一致する場合、「'AB'の個数」+「先頭が'B'の個数」+\(max(0,「先頭が'B'で末尾が'A'の個数」-1)\)
・そうでない場合、「'AB'の個数」+\(min(「先頭が'B'の個数」,「末尾が'A'の個数」)\)+「先頭が'B'で末尾が'A'の個数」

全ての文字列のすべての文字を1度ずつ走査することが必要であり、かつそれがネックとなるので全体の時間計算量は\(O(N \cdot max(s_i))\)程度で抑えられ、これは制約下で充分高速である。
実装例は以下の通り。


N = int(input())

ab = 0
a_end = 0
b_start = 0
a_and_b = 0
zero_flag = False
for _ in range(N):
    s = input()

    for i in range(len(s) - 1):
        if s[i] == 'A' and s[i+1] == 'B':
            ab += 1

    if s[0] == 'B' and s[-1] == 'A':
        a_and_b += 1
    elif s[-1] == 'A':
        a_end += 1
    elif s[0] == 'B':
        b_start += 1

answer = 0
answer += ab
answer += min(a_end, b_start)

a_end -= min(a_end, b_start)
b_start -= min(a_end, b_start)

if a_end == 0 and b_start == 0:
    answer += max(0, a_and_b - 1)
else:
    answer += a_and_b

print(answer)
0個の時を見逃してWAするなどした。
