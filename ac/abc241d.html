ABC241D Sequence Query

問題文はこちらから。
数列の特定の値から見て何番目かの値を答える問題。

Sortedcontainer.SortedListを使えば解ける。
挿入と、大きさを見てのサーチが両方ともそこそこの早さで行えるというところにありがたさがある。
公式のsortedcontainersライブラリを使っても定数倍があまり気にならない程度の速度で終わるだろう。
大きい順/小さい順にk番目の値がない場合は、条件を満たす中で最も大きい/小さい値のインデックスをkずらして範囲外参照にならないかどうかを見ればよい。
実装例は以下の通り。

import sortedcontainers

Q = int(input())

A = sortedcontainers.SortedList()
for _ in range(Q):
    query = list(map(int,input().split()))
    if query[0] == 1:
        A.add(query[1])
    elif query[0] == 2:
        x, k = query[1], query[2]
        a = A.bisect_right(x)
        a -= k
        if 0 <= a:
            print(A[a])
        else:
            print(-1)
    else:
        x, k = query[1], query[2]
        a = A.bisect_left(x)
        k -= 1
        a += k
        if a <= len(A) - 1:
            print(A[a])
        else:
            print(-1)
この問題そのものは解くだけなら大したものではないが、公式解説に「●●でも解けます」系統の話が多く、強い人たちの知見を色々得られるのが面白い。
