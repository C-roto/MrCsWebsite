ABC137D Summer Vacation

問題文はこちらから。
日雇いバイトをこなして何日か後に報酬をもらう問題。

先頭から見ていくと「先にこっちを取った方が有利か？」みたいなのが大量に発生してキツい。
これは「先に進むにつれて選択肢が減っていく」から発生する現象であり、こういう場合は期限である\(M\)日後から順に遡るようにして見ていくと視点がすっきりする。
つまり、\(M-k\)日目の時点では、報酬の受け取りが\(k\)日後以内のバイトをすべて見て、その中で報酬が最大のものを選べばよい。
こうすると常に選択肢は増える一方なので、あとからより良い選択肢を選べたかも……と考える余地がなくなる。
すべての選択肢を一度ずつ見て、最大値を出すのはヒープに突っ込めばよい。時間計算量は\(O(N+M\log_{}{N})\)程度で済み、この制約下なら問題ないと思われる。
実装例は以下の通り。

import heapq

N, M = list(map(int,input().split()))

Works = []
for _ in range(N):
    Works.append(list(map(int,input().split())))
Works.sort(reverse=True)

HQ = []
heapq.heapify(HQ)

answer = 0
for m in range(1, M + 1):
    while Works:
        if Works[-1][0] <= m:
            a, b = Works.pop()
            heapq.heappush(HQ, -1 * b)
        else:
            break

    if HQ:
        q = heapq.heappop(HQ)
        answer += -1 * q
print(answer)
シンプルな問題。水diffとあったが、今なら茶diff程度でもおかしくない問題だろう。
