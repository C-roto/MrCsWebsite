ABC441E A > B substring

問題文はこちらから。
文字列の中で、特定の文字が特定の文字より多いかどうかを調べる問題。

dp的なことをするのかなーと思ったが、保持しておくべき情報量がとにかく多くなることに気が付いて困った。
「AがBより大きくなる」タイミングを特定するには、AがBより何文字多いかという情報を常に保持しておく必要があり、単純にdpテーブルを作ると\(O(N^2)\)サイズになってしまう。
そういうわけでどうしたらいいかを考えていたが、遷移手順を紙に書いてじっと見てみると案外簡単に思いついた。
例えばABACCという文字列があったとしよう。
この時、「\(i\)文字目を末尾としたときの\(Aの文字数-Bの文字数\)」を考える。
この例だと1文字目はAなので、これを末尾とする文字数の\(Aの文字数-Bの文字数\)（長いので以下A-B差と呼ぶ）は1のものが1つだけある。
その状態は[1:1]と書ける。今回は他のものがないことを明示するために[..., -1:0, 0:0, 1:1, 2:0, ...]と書いてみる。
例えば2文字目についてみると、2文字目を末尾とする文字列のA-B差は0のものが1つ、-1のものが1つある。
つまり、状態としては[..., -1:1, 0:1, 1:0, 2:0, ...]となる。
同様に3文字目について考えると、[..., -1:0, 0:1, 1:2, 2:0, ...]となる。
インデックスを省略して並べて書いてみる。
1文字目：[...,0, 0, 1, 0, ...]
2文字目：[...,1, 1, 0, 0, ...]
3文字目：[...,0, 1, 2, 0, ...]
4文字目：[...,0, 2, 2, 0, ...]
5文字目：[...,0, 3, 2, 0, ...]
こうしてみてみると、0でインデックスされた地点に数字を足して、数列全体を左右にスライドしているような感じになっているのが分かるだろうか？
そして、\(i\)文字目を末尾とするものの中で問題文の条件を満たすのは、0でインデックスされた場所より右にある数の合計（つまりA-B差が正のものの合計）である。
各回で数列はそれほど大きくスライドしないので、別で管理する変数を持って置き、正か0以上かが切り替わったタイミングをチェックして変数に手を加えればよい。
イメージ的にはチューリングマシンを考える時のテープとヘッドみたいなものを想像してもらえると良い。
充分に長いテープを用意し、ヘッドを真ん中らへんのどこかにセットする。ここを「0」の位置とする。
文字列の最初の1文字を見て、Aならヘッドの右に1を書き込み、Bならヘッドの左に1を書き込み、Cならヘッドの位置に1を書き込んでおく。
変数\(now_a,anser\)を用意し、両方ともヘッドより右にある1の個数で初期化する（つまり1か0になる）。
ここから次の操作を行う。
・今ヘッドがある位置に1を書き込んだのち、\(i=2,3,...,N\)文字目を見る。
→その文字がAなら、今ヘッドがある位置に書かれた数字を\(now_a\)に加算し、ヘッドを1つ左に動かす。
→その文字がBなら、ヘッドを1つ右に動かした後、ヘッドが移動した後の位置に書かれた数字を減算する。
→その文字がCならヘッドを動かさず、何もしない。
・上記ヘッド移動後の\(now_a\)の値を\(answer\)に加える。
テープはNの定数倍オーダーで事足りるし、各回の計算も定数時間で行える（数列ではなくヘッド（の位置を示す変数）を動かせばよいから）ので、時間計算量は\(O(N)\)程度で抑えられる。
実装例は以下の通り（上記説明の\(now_a\)が\(a_value\)、ヘッド位置がpivot、テープがchechtableである）

N = int(input())
S = input()
checktable = [ 0 for _ in range(2 * N + 1)]
pivot = N
a_value = 0
if S[0] == "A":
    a_value += 1
    checktable[N + 1] += 1
elif S[0] == "B":
    checktable[N - 1] += 1
else:
    checktable[N] += 1

answer = 0
answer += a_value

for i in range(1, N):
    checktable[pivot] += 1
    if S[i] == "A":
        a_value += checktable[pivot]
        pivot -= 1
    elif S[i] == "B":
        pivot += 1
        a_value -= checktable[pivot]
    answer += a_value

print(answer)
解いてみると、何で解けなかったのかと思うほどシンプルな問題。
でもNovistepsで1D扱いされているということは、まあそんなやわな問題でもないのかもしれない。
